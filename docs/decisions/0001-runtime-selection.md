# ADR-0001：翻译中间层运行时选择

**历史决策依据。** 下文实验与 M1／M2 安排属于已归档的 0.0.0 阶段，不作当前版本验收。Cordis／DSH 复用原则由 [ADR-0002](0002-plugin-composition-0.1.0.md)继续约束；后续固定版本的服务和生命周期草案见 [0.1.x 契约](../requirements/0.1.x/contracts.md)，实际可用范围见[能力表](../plan/0.1.0/capabilities.md)。

日期：2026-09-29｜状态：M1 实验支持，作为 M2 实现路线。

## 决策

采用 Cordis 组织服务，优先复用 DSH 的 `LlmRuntime`、`llm-pi-ai` 及其请求／响应类型和配置解析。先建立小型翻译程序，不启动完整 DSH 的 agent、会话、工具和 UI 子系统。业务层自行实现术语选择、翻译任务和已接受译文存储，不重写已有模型提供商适配。

后续选型补充：上述是 M2 起步范围，不是候选准入限制。[选型 v1.1](../research/tool-selection-v1.1.md)纳入 DSH 和其他 Cordis 软件的插件；需要 settings、storage、session、workspace 或部分宿主能力的组合也可以采用，按实际节省的工作量与接入代价决定，不以完全独立为前提。

实验使用 DSH 提交 `639ed015397290b3745d163aafe02ffee4aa3f84` 中配套的 vendor Cordis；不把上游 Cordis HEAD 与这套内部模块随意混装。M2 先固定已验证版本，源代码接入／打包方式沿用实验最小依赖闭包，再按真实需求缩小接口。

## 证据与取舍

真实的 Cordis、DSH 模型运行时和 pi-ai 插件已连接本地模拟 HTTP/SSE 服务。实验验证流式结果、模型端点替换、凭据缺失、HTTP 401、取消、消费者关闭、超时，以及依赖缺失与卸载后的监听清理。无需真实模型密钥，未启动完整 DSH。命令和详细结果见归档分支的[实验说明](https://github.com/KongouAirlines/ivaraige/blob/codex/archive-mvp-0.0.0/experiments/cordis-dsh/README.md)与当前保留的[源码研究](../plan/mvp/m1/cordis-harness.md)。归档代码也可用标签 `v0.0.0` 查阅。

| 路线 | 本轮证据 | 安排 |
|---|---|---|
| Cordis + DSH 模型模块 + 翻译业务层 | 真实最小依赖闭包运行成功，可复用端点、流式、错误和取消处理 | M2 采用 |
| 完整 DSH + 翻译插件 | 尚未证明完整应用的会话／agent／UI 对当前文本闭环有必要 | 暂不引入；后续需要界面时重新评估 |
| 普通模块化程序，自行接模型 | 可减少框架依赖，但会舍弃本轮已验证可用的接入能力 | 保持业务接口可替换，不另写一套作为备用 |

这不是对三条路线进行过同规模性能比较的结论；选择依据是已跑通的复用能力与当前工作范围。

## 实现边界

- 模型适配层接收文本、模型配置和取消信号，向业务层返回文本、结束原因及可确认的用量。术语选择与译文是否复用由业务层决定。
- 提供商不返回 usage 时，当前 SDK 会补零。不能据此记为零消耗；M2 需要保留用量是否确知的信息，未知记为空／unknown。
- 实验读取固定版本源码并打包，尚不等于已取得稳定、可独立发布的 DSH 公共模块包；升级时只验证实际受影响的接入边界。
- Python PDF 重建通过独立进程衔接，输入已保存译文，不让输出步骤重新调用模型。具体证据与局限见[PDF 实验](../plan/mvp/m1/pdf-translation-injection.md)。
- 保留复用源码的许可证与归属；本轮第三方克隆及打包产物均忽略提交。模块许可与 PDF 核心许可分别记录在研究文档中。

若后续独立接入成本明显增加，或确需复用 DSH 的完整界面／任务能力，再调整此决策。无需为尚未发生的变化预建第二套运行时。
