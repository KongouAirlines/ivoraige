# 0.1.x 可组合工作流与内容工作台草案

本页是待实施设计，补充[基础契约](contracts.md)，不是当前能力或已固定的数据库 schema。实施范围、依赖和状态只在[工作包表](../../plan/0.1.x/work-packages.md)维护；候选版本见[分期](../../plan/0.1.x/releases.md)。2026-10-20 的设计目标是把可保存、可追溯、按需组合落实到业务执行，而不是只给固定 parse → translate → export 更换界面。

## 当前与目标

当前内核已有导入、翻译、冻结导出和持久记录；当前入口没有通用可保存工作流或完整项目图模型。v2 的固定用例和入口继续作为兼容路径，不能据此限制以后只有一种流水线。普通短文翻译仍可直接操作，不强制先建项目、挑模板或画图。

目标中，项目是长期工作上下文，绑定文档、资源、所选能力和工作流实例；同一项目可以包含多个实例。模板是可复用配方，运行是某次执行记录，插件是提供能力的生命周期单元，四者不同。项目中的文件集合不自动决定所有节点的输入；每次运行必须明确选中哪份资源、哪个版本和哪种授权范围。

以下都是有效目标：只解析并导出原文结构；准备术语候选并人工确认；将同一来源送入两个不同参数的处理分支，比较后选择一个修订；人工接受一次译文后生成多个格式的冻结成品。处理、翻译、校验、人工决定和输出能力可以组合，同一能力可在不同节点重复配置。

## 定义、绑定和运行分层

以下字段是职责示例，最终名称/存储模式由 W01/W02 的兼容评审决定。

| 对象 | 保存什么 | 可变边界 |
| --- | --- | --- |
| 模板版本 `TemplateVersion` | 模板身份/版本、节点和连接、端口类型/版本、参数 schema、非秘密默认值、所需能力及兼容要求、显式人工点 | 发布为可引用版本后不就地改写；编辑产生新版本。保存/导出不带凭据、用户内容、机器私有路径、运行结果或可解析的私有资源引用 |
| 项目实例 `WorkflowInstance` | 引用的模板版本、可编辑节点/连接/参数、项目资源绑定、当前实例修订 | 可编辑并保存新实例修订；升级模板先预览差异，不自动覆盖本地改动；项目权限不由模板继承 |
| 运行定义快照 `RunDefinition` | 本次实例修订、已知输入的确切版本、有效参数与约束、能力/插件及引擎版本、执行策略、发起者和授权引用 | 受理后不可原地改成另一配置；密钥通过受控 credentialRef 在执行时解析，不能把密钥写进快照 |
| 执行片段 `ExecutionSegment` | 本片段已经确定的输入/决定版本、依赖、实际实现版本与后续计划 | 人工点前只冻结已知事实；决定后追加新片段，关联确切决定及输入。不能假定 run 创建时已知道未来人工结果 |
| 运行/节点状态与尝试 `RunState / Attempt` | queued/running/等待人工/成功/失败/取消等状态、任务引用、尝试次数、实际输出、错误及外部执行不确定性 | 状态可以更新；每次尝试和关键决定有稳定身份及记录。冻结定义不等于冻结全部状态，也不把失败尝试覆盖成“从未发生” |
| 修订、产物与决定 | 既有 Document/Unit/Revision/ExportSnapshot，加上有类型/版本的产物引用、输入来源链、节点/尝试引用和显式人工选择 | 人工编辑生成新修订；接受与替换遵循原并发检查。旧运行结果与冻结导出继续可追溯，不改写历史来迎合新实例 |

全局默认、项目覆盖和本次/步骤覆盖的界面归属见 [UI 设置契约](ui.md#三层归属与设置标签)。受理时解析并记录有效值及来源；后续全局默认变更不热改在途或历史运行，恢复不能暗换模型、连接或授权范围。

运行定义只保存必要的引用和有效参数；项目资源与共享模板的访问域分开。来源链能回答“谁用哪个能力/版本、对哪些输入与约束、在何次尝试中产生了这个结果，以及后来接受了什么”，无需为每条进度通知建设完整事件溯源系统。外部模型结果记录当次返回及可获得的版本/usage；无法得到的值标 unknown，不承诺同一输入逐字重跑相同。

## 能力、端口与依赖

节点引用已注册的能力/operation，不持有 Cordis Context 或服务定位器。能力提供者声明输入/输出类型及 schema 版本、单值/集合基数、参数 schema、约束、取消/暂停/恢复/缓存能力，以及是否涉及模型费用、网络、文件写入或外部副作用。不支持某种控制或无法判断安全复用时须明确标注，不能假定所有操作都可暂停、可恢复或可缓存。节点只是能力调用实例，不为每个节点创建新 Cordis 插件框架；插件自己的 inject/effect/disposer 仍由 Cordis 管理，装配和版本来源仍受 P01/P05 约束。

产物至少区分受管理资源、结构化原文、修订集合/显式接受结果、冻结输出及外部对象引用；具体载体可复用既有 Records/Artifact，不另造一份文档真相。类型/版本可兼容时才可连接；格式名称相同不证明来源绑定或 renderer 可用。转换必须是显式能力节点，不能偷偷重解析、换引擎或把候选译文当已接受结果。二进制产物和可读视图是不同投影。

首轮以有限、可验证的有向无环依赖为范围，支持分支、汇合和显式人工点，不承诺循环、任意脚本、动态代码、无限递归或外部插件沙箱。受理前检查节点/端口存在、连接方向、类型/版本/基数、必需输入、循环、能力可用性与副作用声明；单值不能暗转集合，集合映射/收集规则必须显式。缺件/升级不兼容明确不可运行，禁止静默替换。

分支的扇出输入引用同一个确定版本，分支输出各自保留。汇合须声明是收齐必需输入、选定分支或显式允许的部分结果；空分支、失败、取消和人工拒绝不可冒充成功。人工步骤暂停受影响的下游，独立分支按已声明策略继续或取消；不得让占满 jobs 配额的等待任务阻止用户作出决定。选择结果后仅形成获准的后续片段。

## 编排、资源与恢复

编排层验证业务依赖、生成执行计划并关联运行/尝试/决定；实际调度、并发配额和取消复用 `ivoraige.tasks` 与 DSH jobs。它不另建线程池、任务内核、DI 或 Loader。节点调用与既有 operation 共用参数/权限/错误规则，独立 CLI/MCP/HTTP 操作仍可直接使用，不必先包装成图。

受理后获取所需资源 lease，开始前复核已冻结实现仍可用；任务结束、取消、失败或放弃时释放本次持有的引用。插件禁用/升级默认重启生效，不能销毁运行中的提供者或删除旧记录需要的资源。恢复时核对确切插件/契约/引擎及输入版本；不匹配则保留结果与诊断，等待显式恢复或新建运行。退出先停止新运行和新片段，再按已声明 task kind 完成暂停/取消/持久化，最后释放服务与存储。

持久化范围是运行定义、片段、节点尝试、任务映射、输入/输出引用、关键决定和副作用结果收据；瞬时 UI 进度不要求逐条永久保存。重启沿用当前未完成任务暂停、显式恢复原则，不能把旧导入任务自动升级成可续传任务。

历史迁移保留已有文档、修订、任务和产物身份；当时未记录的输入快照、插件版本或完整血缘标为缺失/未知，不能按当前设置伪造。可由旧配置生成明确标为“新草稿”的流程供核对，新草稿不是旧任务当时执行过的定义；默认处理链转为组合定义时仍保留旧入口行为及兼容记录读取。

## 编辑、复用和副作用

模板或实例变化只影响新的运行/片段。旧成功运行保留成功事实；当前实例视图可将受影响节点及其有效下游标为“待更新”，这不是把历史运行改判失败。人工编辑创建新修订，不自动替换已接受成果；分支比较、选择与接受分别留痕。

复用键不能仅是节点 ID 或输入文件摘要。判断须覆盖确切输入修订、来源绑定、有效上下文/目标/术语约束、参数、能力/实现版本及其兼容政策；沿用既有 applicability 检查。无变化分支可复用，受影响部分另作新尝试，显示沿用了哪个旧结果；不得用“重新运行全图”掩盖重复收费或覆盖用户编辑。

| 操作类别 | 重试与恢复要求 |
| --- | --- |
| 可重复的本地计算 | 新尝试记录，输出先暂存后原子登记；取消只清理本次拥有且未引用的资源，不覆盖源文件 |
| 模型或远端识别调用 | 记录请求/供应商关联信息与未知执行结果；能查询状态先查询，不能确认时显式告知再次调用可能收费，由用户决定是否重试；不宣称 exactly-once |
| 导出文件 | 继续由导出受理创建 `ExportSnapshot`，只消费接受或 source 模式的冻结数据；确定目标身份与冲突政策，避免多次重试生成重复/覆盖成品。导出节点不能访问翻译模型 |
| 外部上传/附加附件/写回 | 写前预览目标与内容并取得明确确认；记录幂等键/关联对象/结果收据，超时后先查询，不盲目重传；删除本地记录不等于撤回外部副作用 |
| 人工决定 | 记录决定者、所见输入/基修订、选项与结果；过期决定或并发变化要求重新核对。决定后追加执行片段，拒绝与取消有各自结果 |

审批或接受后，实际决定才成为后续输入。需要改变已冻结的前置配置或替换输入时创建派生运行，保留来源关系；不能“恢复旧运行”时偷偷改用新的模型、插件或文件。

## 内容优先的交互

进入项目或文档后，默认进入内容工作台：正文、原译文对照或文件预览占主区域；普通操作仍可一键开始。常驻流程信息只用轻量状态条显示当前运行、等待人工/失败、取消/恢复入口；状态条不替代任务详情，也不要求用户持续看图。

全局导航与独立普通翻译见 [UI 草案](ui.md)，普通页默认是原文/译文输入区，不要求进入本工作台。这里的右侧检查面板与左侧全局导航职责分开。

可折叠侧栏提供步骤列表、所选节点参数、输入/产物来源与尝试记录，点击定位相关文件/页码/选段。复杂编排通过明确入口进入独立编辑模式；退出编辑模式时恢复先前文件、页码、选段、滚动位置和未保存草稿。浏览器与候选桌面壳共用模型；无需等待原生桌面交付才实现此工作台。

模板/卡片编辑和高级节点图是同一工作流模型的两种视图。简单视图无法表示的分支/汇合仍须保留并显示提示，可只读或引导高级编辑；返回简单视图绝不静默拉直、删节点或丢参数。先交付可访问的列表/卡片与参数校验，高级图编辑可后置，不锁定 React Flow、画布库或桌面框架。

基础编排编辑必须能增删/替换操作、选择实际输入与目标输出、保存/另存和查看定义版本；局部重跑先显示有效依赖闭包和将产生的副作用。选择目标输出只执行其必要前置和显式确认的动作，不自动运行无关分支或上传节点。删除操作先检查依赖并保留已存历史，不能因卡片操作删除用户成果。

选中节点不是执行或批准；预览显示影响范围、输入版本、将复用/将重算的部分和费用/外发风险。运行定义锁定后，编辑当前实例不会热改在途执行。人工确认界面直接展示待选结果和对应内容，确认后仍返回内容上下文；关闭面板不等于批准、暂停或取消。

未保存草稿与已提交修订分开显示。模式切换保留编辑状态，自动销毁窗口必须等待 D02 的可靠落盘确认；保存失败阻止销毁。恢复承诺只覆盖最后确认持久化的数据，不保证崩溃后找回所有未保存按键。键盘/读屏可完成模板选择、连接关系理解和人工确认，小窗口折叠面板仍保留正文。

## 分期与最小证明

- W01 纳入 0.1.0：默认处理链以可组合定义表达；P02/P03 的通用结构/来源/产物、P04 能力描述与执行接线真实支持组合。用实际能力插件证明至少两种不同拓扑，例如纯结构化建库/输出，以及同能力多配置的分支 → 比较汇合 → 人工决定 → 后续输出。不能靠两条硬编码流水线或仅画 UI 模型通过；CLI/测试驱动即可，不要求完整模板管理界面，也不将最小建库样例冒充完整 RAG 产品。
- W02 紧接基础独立交付模板版本、项目实例保存、运行/尝试/决定持久化及恢复，包含增删/替换、输入选择、保存/另存/版本化、目标输出运行和局部重跑；W03 交付内容工作台和无损模式切换。它们依赖基础契约，不依赖 D05 原生壳，也不等待完整多项目/共享权限产品化；可保存真实组合不能无限期后置。
- W04 后续高级图编辑沿用相同模型，先证明复杂图的往返不丢信息再扩大交互；不以选定图形库代替模型与恢复验收。

工作包、范围/不做项/回退与 W-V01–W-V04 验收集中在[工作包](../../plan/0.1.x/work-packages.md)和[验证矩阵](../../plan/0.1.x/validation.md)。未定项包括：最小 Project 所有权、模板迁移/共享格式、具体产物 schema、分支失败政策默认值、授权有效期、外部幂等能力及 UI 布局细节；先以最小合规样例固定边界，再按真实能力扩展。
