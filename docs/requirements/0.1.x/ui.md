## 全局导航与主页

左侧是应用导航，右侧或窄屏抽屉是当前内容的步骤/参数检查面板；两者不共用栏目定义。侧栏可收窄，“资源与扩展”可折叠，内容阅读/编辑占主区；小屏按需打开导航与检查面板，不让两栏同时挤占正文。格式、引擎和工作流步骤不固定成为一级导航。以下为已纳入规划的候选布局，尚未实现。

| 区域 / 栏目 | 职责与显示条件 |
| --- | --- |
| 全局：主页 | 双入口“新建项目”“进入普通翻译”，下方最近/已有项目列表；首次使用允许空列表。项目能力未交付时不显示无效新建按钮，普通翻译能力缺失时显示明确安装/修复引导；不假装可运行 |
| 全局：普通翻译 | 独立原文/译文文本页，无需项目、文件导入、模板或画布；已有草稿和手动编辑在无模型时仍可用 |
| 资源与扩展（可折叠）：模型 | 直接进入[模型与提供商连接管理](#模型与提供商连接管理)，不埋进插件管理 |
| 资源与扩展：术语与知识库 | 独立库、候选确认、导入导出、适用范围与项目挂载；按实际已交付能力展示，不把词语编辑自动变成共享规则 |
| 资源与扩展：插件与功能 | [插件管理与配置](#插件管理与配置归属)入口；最小管理/恢复不依赖某个业务插件 |
| 资源与扩展：软件联动 | 已安装桥接的连接、权限、状态与使用入口；与插件安装页互相定位，不把常用联动埋进设置 |
| 分隔线下：具体项目 | 每个项目独立入口，附“新建项目”；打开后显示该项目文件、内容、目标、已选能力/术语与结果，工作流按需展开 |
| 固定底部：任务 | 跨项目任务/失败/等待人工与取消恢复，任务数保持可见，资源组折叠不隐藏任务入口；项目内可筛选，不另存一套状态 |
| 固定底部：设置 | 打开[五类设置](#三层归属与设置标签)，按已交付能力呈现 |

这是目标信息架构，不要求本轮把所有页面做成空壳。业务栏目由实际页面/能力贡献注册；未安装的业务能力到插件管理发现，不堆满空白或置灰菜单。已安装但暂不可运行的页面保留状态与修复路径；已有项目引用缺失插件时始终保留项目、历史和诊断入口。首页软件联动快捷卡可后置，不改变固定的全局联动位置。

普通翻译、术语、管理和具体项目是不同工作上下文。项目用于持续组织文件、目标、约束、人工修订和产物，资源可复用，但项目的目标语言、接受决定、私有内容及授权不能跨项目自动传播。普通翻译可显式加入新/已有项目，保留 documentId、来源与修订/审阅历史，不重新导入或重新收费翻译；最小 Project 绑定由 W02 提供，尚未交付前保留普通记录，入口不假装转入成功。

旧 `#/documents`、文档详情、`#/pdf`、PDF 任务及 `#/translate` 深链保留可诊断的兼容入口：定位原记录/任务或对应能力页面，保留查询参数与身份，缺能力转到该记录的修复说明；不得把所有 PDF 链接重定向首页或静默换引擎。`#/settings/pdf` 中的资源/插件配置操作迁到插件详情，并给旧深链明确迁移指引。最终路由名由实现切片确定；页面 ID 与插件 ID 分开，一个插件可以贡献多页，多种插件也可贡献同一能力页面，不恢复前端硬编码引擎名单。

## 三层归属与设置标签

| 层次 | 管什么 | 不混入的内容 |
| --- | --- | --- |
| 主侧栏对象管理与工作入口 | 模型/连接、库、插件、桥接等对象的增删、组织、状态及进入工作；项目组织持续处理上下文 | 不用一个全局设置表承载所有对象及本次处理参数 |
| 应用设置 | 跨对象全局默认、宿主运行与资源策略；可链接到同一对象管理器 | 不复制模型/连接/插件配置，不按每个插件增加一个顶层设置标签 |
| 普通翻译、项目与步骤 | 本次模型/连接、引擎、术语、风格、输出格式及生成参数；可见继承值和本次覆盖 | 不因修改本次温度等参数而修改所有项目默认，不要求到全局设置才能调整本次生成 |

五个候选标签及其职责如下；这是目标信息架构，不表示这些控制已经实现，也不新增宿主能力承诺。

| 设置标签 | 内容与边界 |
| --- | --- |
| 通用 | 界面语言、通用应用行为及跨对象使用默认；全局更新检查/更新策略分组。具体插件安装、升级执行仍在插件管理，策略设置不等于授权自动安装 |
| 外观与交互 | 主题、密度、侧栏/面板及内容布局偏好、键盘与可访问性交互；不是新的业务页或强制常驻工作流图 |
| 连接与运行 | 打开同一个模型/提供商连接管理器；单独设置即时预览默认模型，不继承正式翻译模型，设置不等于启用；全局并发、超时、重试默认及宿主运行限制，插件获取来源/受控来源策略分组。连接端点、凭据引用等对象字段仍由该管理器维护；实际能力上限不能靠本次覆盖绕过 |
| 数据与存储 | 稳定可直达的存储维护子页，范围及恢复边界见[数据管理](#术语知识库与数据管理)；项目文件/译文导出留项目或结果页 |
| 关于与诊断 | 软件与实际组件版本、许可信息、运行/连接诊断入口及脱敏诊断信息；连接对象测试仍回到同一管理器。诊断导出不得包含凭据和私有正文，不能把“关于”扩成另一个插件安装页 |

未交付的控制不以空白或置灰页面充数；五个分组内逐项随能力启用，稳定的数据与存储入口随相应管理切片交付。插件贡献适配现有分组或插件详情，不随插件数量无限增设标签。账户/凭据状态不暗示已有登录、多租户或完整权限产品。

默认解析顺序为全局默认 → 项目明确覆盖（普通翻译可无项目）→ 本次翻译/步骤覆盖；界面标明每个有效值来自哪层，并允许清除覆盖、恢复继承。未提供某层时沿用上层，仅允许能力 schema 支持的字段；风格等尚未交付能力不展示假选项。运行受理时记录实际模型/连接身份、引擎及版本、术语/风格版本引用、格式和有效生成参数，沿用 W01/W02 的冻结运行定义，秘密只保留受控引用。全局默认变更只影响以后重新解析的草稿/新运行，已有显式覆盖不被抹掉；在途及历史运行、接受修订和冻结输出不静默改写。恢复旧运行需核对其确切配置/兼容性，不能借“继承最新默认”暗换模型或连接。已获外发授权也不能因默认连接变更自动扩大。

全局并发/超时/重试分清默认与硬限制：任务可以在声明支持的范围覆盖默认，但不能突破宿主限制；未支持的控制明确不提供。模型或外部写回的执行结果未知时，重试策略不能覆盖既有查询/显式决定规则，不因为设置“自动重试”重复收费或重复写入。

## 模型与提供商连接管理

主侧栏的“模型”直接进入对象管理页，日常主要入口包含模型列表和提供商连接列表。设置的“连接与运行”打开同一管理器、同一对象及编辑状态，并保留返回上下文；未保存变更仍用既有离开保护，不维护第二套表单数据源或新凭据库。旧 settings/models 深链兼容定位同一管理器，不静默丢失编辑。

| 对象 | 职责 |
| --- | --- |
| 插件提供方 / 能力实现 | 提供可用协议、适配能力和参数 schema；其安装/启停及高级专属配置归插件管理，不等于某个账号或端点 |
| 提供商连接实例 | 用户配置的一组端点、协议/提供方引用及受控凭据引用，有独立身份和可用状态；同一提供方可有多个连接，一个连接可服务多个模型 |
| 模型对象 | 引用连接和远端模型标识，维护别名、能力声明/探测结果、可用状态、收藏和使用入口；不按模型复制一份连接密钥 |

添加模型时可选择既有连接，或在同一流程新建连接并返回；模型管理也能单独添加、修改、测试连接。模型页提供添加/移除和显式测试，别名、能力、状态与收藏按上述对象表管理；能力声明或测试结果不能冒充未经验证的支持。测试前显示范围和潜在费用/外发；仅浏览、刷新配置不得隐式发起计费生成。删除模型不连带删除共享连接，删除/更换连接先列出受影响模型及运行/项目引用，保留历史身份与诊断，不能让同一连接下其他模型静默失效或改用别的连接。

连接底层字段在同一管理器内编辑，跨连接的并发/超时/重试默认及宿主策略在设置；温度、输出长度等本次生成参数在翻译/项目/步骤就近调整，可继承受支持默认。模型下载资源的准备仍在插件详情，模型对象的选择/组织在模型页，不能把“有模型记录”当作资源已就绪。

以上是对象与入口职责草案，具体标识/schema 和现有 provider/model/profile 配置的迁移在 U02 与基础契约接线时固定，复用 DSH 服务及凭据引用；旧连接关系无法可靠推导时显式核对，不凭名字合并用户端点，不授权重建连接基础设施。

## 独立普通文本翻译

原文输入框可键入或粘贴，译文区可阅读和手动修改；宽屏左右双栏，窄屏上下排列。语言、实际可用模型/方案、翻译按钮、取消、复制和修订历史就近呈现；本次生成参数按需展开，显示继承来源与覆盖，不全藏进全局设置。工作流、文件列表和节点图不占据此页默认主区。手动输入/编辑/保存不要求模型可用；翻译动作才要求可用翻译能力及目标语言。缺翻译插件时明确不可调用，不阻断已有内容查看。

默认关闭自动预览，输入、编辑和保存不触发模型调用，替代 v2 §5.3 的默认 500ms 自动翻译目标。用户可主动开启下述即时预览，使用单独指定的已配置模型；正式翻译/精译仍需明确点击，不随输入或预览失败自动执行。请求前可见所用服务、将发送的选区及必要上下文、费用估计或未知状态；取消后的远端执行/计费不确定性沿用工作流恢复契约，不伪报零费用或盲重试。

### 可选即时预览

这是 U01 的候选切片，尚未实现，具体版本待验收。近期复用用户已配置的模型连接，经既有 DSH 模型/任务服务调用；在设置中单独配置“即时预览默认模型”，只引用已有连接与模型，不自动继承正式翻译模型。普通页就近显示预览开关、实际模型/连接、语言方向和可用状态，并提供配置入口；选择模型不等于开启自动预览。用户需要本地预览时可自行运行 LM Studio 等服务并手动配置连接，不要求应用内置引擎或下载语言包。

自动预览默认关闭，任何连接都须由用户明确启用。外发边界按实际请求端点及代理/转发路径判断，不按提供商名称、“本地服务”预设、模型或连接 ID 判断。局域网、自定义远端以及无法确认是否仅在本机处理的连接，启用前均提示可能外发；`localhost`/回环地址只说明接入点在本机，不能证明服务不转发或完全离线。提示展示实际端点（协议、主机、端口及路由路径，隐藏凭据）、已知代理/转发目的地及未知部分、下述 payload 范围，并说明“开启后会随输入停顿自动发送这些文本和约束，可能产生费用”；费用未知须明示。取消或未确认均不调用。正式翻译/精译的点击授权与自动预览的启用选择分开。

启用选择绑定模型/连接身份、实际目的地、影响目的地的连接/代理配置修订，以及 payload 范围与约束配置修订。每次发送前重核，不能只比较模型/连接 ID。更换模型/连接、同 ID 原地修改端点/代理、发送范围或约束配置变化时先暂停，取消待发/在途工作并丢弃旧结果；重新展示目的地、范围和潜在费用并明确确认前不发送。允许重定向的调用也不得把正文或凭据自动转发到已确认目的地范围之外；发现新目的地时先停止并重新确认，不能先跟随后补提示。无法核对应用实际发送目的地或配置修订时保持暂停；服务内部后续处理不可知时须明确提示其不确定性，不能冒称仅本地处理。已发请求的远端执行和计费不保证可撤回。

#### 预览请求内容与版本

近期普通页以当前原文输入框的全部文本为一个明确可见的预览范围，不因光标、选区或自动分段猜测改为更大范围；空文本不调用。下表定义可发送集合，启用提示逐项显示是否包含及具体范围，发送时与实际序列化请求一致；不把“必要上下文”作为任意追加内容的通道。每次键入只更新已确认输入框中的内容及其版本，不要求逐字重新确认；更换来源对象或改变下列发送规则须按上述规则重新确认。

| 内容 | 默认与允许范围 | 发送及版本依据 |
| --- | --- | --- |
| 最小 payload | 当前输入框原文、源语言（或明确自动识别标记）、目标语言、固定的只输出译文指令，以及所选模型标识和已展示、受支持的温度、输出长度上限、停止条件等纯生成控制参数 | 均属于发送集合；固定指令/模板及生成配置有可比对版本，未列明且携带用户内容的提供商扩展字段不发送，不能从其他项目或历史对话暗中补提示词 |
| 相邻文本与背景上下文 | 近期不带相邻段落、输入框外的原文/选区上下文、译稿、历史修订或对话、项目/文档全文、检索片段和附件 | 不发送；输入框本身含多段时这些段落属于已展示的原文范围，不额外读取相邻内容 |
| 术语约束（可选） | 默认不选库；用户明确选择且术语能力可用时，按领域/项目/来源/章节适用范围先过滤，再匹配语言方向、词形及义项，最后处理库优先级与冲突 | 只发送已确认、适用且命中的源词、目标译法及必要的消歧/使用限制；启用提示显示所选库范围和这一动态筛选规则，当前有效条目可查看。不发送整库、无关项、来源证据原文或库元数据；来源未知时不强用文献专用义项，冲突或显式选库但能力缺失时暂停，不静默忽略。遵循[术语契约](contracts.md#术语服务与翻译复用)与[补充 0001](../amendments/0001-term-applicability.md) |
| 风格与用户指令（可选） | 默认不附加；仅允许用户为本次预览明确选择并展示的风格文本或翻译要求，不能继承正式翻译、项目或工作流的隐藏指令 | 实际文本随请求发送，绑定所选内容及版本；修改先暂停并重新确认 |
| 抽取配置与其他本地信息 | 不运行术语抽取，不携带抽取配置、文件路径、来源证据、诊断信息、内部记录/授权 ID 或配置对象 | 不进入模型 payload；凭据仅经既有受控认证通道提供给获准目的地，不进入提示词、范围展示或日志 |

每个预览任务在本地冻结原文对象/单元身份（无持久记录用草稿身份）、原文及译稿版本、语言、实际有效上下文/约束及版本、模型/连接与目的地配置修订、启用选择及范围版本。术语额外绑定所选库、命中义项/范围及有效约束版本；这些内部身份用于适用性与过期检查，不因绑定就发送给模型。输入变化可按同一已确认规则重新筛选命中项；库内容/范围、风格、模板或约束配置版本变化须暂停并重新确认。来源缺失不能伪造为通用作用域。上述为语义要求，复用既有任务、修订和配置服务，不新增 wire schema、模型管理器或调度基础设施。

#### 触发与结果保护

开启后，原文停止输入并达到防抖间隔才提交预览；输入法组词（composition）期间不提交，组词结束后重新计时。新输入、清空、语言/约束/模型变化、目的地/相关配置或发送范围变化、关闭预览或离开页面时取消旧任务；服务无法立即中止时仍须丢弃过期结果，不能积压每次按键的请求。防抖间隔只决定何时触发，不等于译文完成时延；实际连接和模型的端到端时延须实测，不承诺实时性能。取消云端请求不保证远端停止执行或免计费。

预览明确标为“即时预览”并显示实际模型/连接，与可编辑译稿和已接受结果区分，不能将云端结果标为本地计算。请求绑定原文及译稿版本、语言、有效约束和模型身份，采用下述候选过期与修订保护；未产生持久记录时使用可比对的本地草稿版本。结果只能更新仍匹配的预览区，不能覆盖人工编辑或已接受结果；用户显式采纳后才按既有修订模型保存，不自动移动 accepted、进入术语库或成为冻结导出的依据。

未指定预览模型、连接不可用、模型不可用、不支持语种或调用失败时暂停预览，显示原因与配置/修复/关闭入口，保留原文和译稿；不得静默回退到正式翻译模型、其他本地或云端模型，也不得借诊断外发正文。恢复须核对原选择的可用性与授权；更换模型遵循上述启用规则。按 [U-V01](../../plan/0.1.x/validation/ui.md#即时预览验收)验证调用、授权与修订保护。

内置推理引擎和语言包仅为远期可选扩展，[候选研究](../../plan/0.1.x/local-translation-preview.md)保留供后续评估，不阻塞近期预览。[Issue #39](https://github.com/KongouAirlines/ivoraige/issues/39) 的 LM Studio 原生 REST 模型发现/加载状态与确认保存配置为独立增强，推理仍走 OpenAI-compatible；手动配置可用，不以该增强为前置。本切片不接管模型下载、加载/卸载、GPU 参数或服务启停。

### 候选与修订操作

| 动作 | 范围与候选呈现 |
| --- | --- |
| 选词/短语替换 | 选中译文范围，按其原文关联和上下文提出候选，预览原词、替换词和局部差异；不得顺带改写全文 |
| 选句重写 | 用户选定一句或明确多句范围，可补充要求；显示实际范围、完整句候选与差异，不靠不可靠断句暗扩范围 |
| 全文重新生成 / 换方案 | 明确以当前原文及约束生成另一份候选，保留旧修订；与局部替换按钮、请求范围及影响提示区分 |
| 手动编辑 | 无模型也可修改译文，保存产生新修订；不把输入过程视为已接受结果 |

所有候选绑定文档/单元、原文修订、目标语言、`baseRevisionId`、选区及有效约束；界面草稿还要有可比对的本地版本。多单元选区须逐单元绑定，不能用字符偏移跨版本猜测。请求期间原文、译文草稿、选区内容、语言或约束变化，迟到结果标为过期，仅供比较/复制或重新请求，不能覆盖新内容；取消、页面切换及响应乱序同样处理。

“采纳候选到编辑稿”和“接受为输出依据”是两个动作。采纳后按既有修订模型持久化新版本，保留生成来源和人工编辑关系，不在本页另造 Revision 真相；不自动移动 accepted。显式接受通过 `expectedAcceptedRevisionId` 检查，并发冲突须重新核对。拒绝候选不改正文；撤回采纳恢复到可核对的先前编辑版本并保留已存历史。若撤回已接受选择，仍需显式接受先前修订及并发检查，不能删除历史或改写既有冻结快照。

“加入术语库”是另一个显式动作：确认原词/译词、含义、来源及适用范围，选择目标库后保存；普通替换或重写不自动形成全局术语。术语功能未安装时保留文本修订即可。读屏/键盘能选择候选、查看差异、拒绝/采纳/撤回；窄屏不依赖悬停才能操作。

## 插件管理与配置归属

界面消费 P04/P05 的权威能力及交付状态，复用 AppBoot/Loader 与既有设置服务，不另建安装器、配置库或任务状态机。安装状态、启用状态、运行就绪和可更新信息分别显示：已安装且启用仍可能因模型/运行依赖/凭据未准备而不可运行，更新可用也不是失败状态。

插件详情覆盖官方来源/版本/兼容依赖、发现安装、引擎/模型/运行资源准备及进度、更新/失败回退、启用禁用/重启生效、卸载、插件专属配置。资源可以作为插件内依赖展示，不要求每个模型另成插件。影响在途任务、已有项目及磁盘占用先说明；卸载插件与删除用户数据分别操作，保留记录及可恢复配置。UI 故障仍可经 bootstrap/CLI 诊断禁用。

按照 [#16 的配置归属补充](https://github.com/KongouAirlines/ivoraige/issues/16#issuecomment-6105527453)，PDF 引擎、模型与运行依赖下载从 settings/pdf 迁到插件管理；应用设置负责通用行为及数据/存储维护。全局准备和复用资源，项目保存实际所选引擎、版本约束、术语及参数，不复制全局安装状态。插件安装/更新/启停/卸载仍在插件管理，插件专属高级配置留详情；全局更新策略、获取来源和运行限制归设置相应分组，两处共用权威配置而不重复存储。**结果文件下载留在项目/结果页**。插件专属参数通过既有设置契约呈现，不以迁页为由重建 DSH settings。

项目缺插件、插件禁用、资源未就绪、版本不兼容或运行失败时，展示确切原因、保留的历史及直达插件详情的修复入口；支持修复后显式继续/新运行，不暗换引擎。新建任务的选择器只列实际可用且类型兼容能力；记录页仍展示历史使用的缺失能力标识，不因隐藏不可用菜单而隐藏证据。

## 术语、知识库与数据管理

术语与知识库保留主侧栏“资源与扩展”组内的直接入口，管理语义资源；“应用设置 → 数据与存储”以独立设置子页管理物理存储和生命周期，提供稳定可直达入口，两页互链但不复制所有权。最小术语流程是手动/导入/抽取候选 → 核对原句和来源 → 确认含义及适用范围 → 入库；可只做术语项目，不要求正文翻译。项目选择一个或多个独立库，先按领域/来源/含义过滤再处理优先级和冲突，记录实际使用版本；库更新不重写旧接受修订或冻结输出。

术语管理接入[后端职责与复用契约](contracts.md#术语服务与翻译复用)，沿用补充 0001；U03 的术语切片须先完成后端接线和双来源验收，不能仅以管理页面证明术语约束已经生效。

库的可见性、显式项目挂载、自动复用和发送给外部模型是不同选择。默认不因“公开”或“私有”标签推定其他权限。完整共享/多用户权限产品后置，但已交付路径必须限制实际读取及外发范围，不以延期为由忽略现有数据隔离。

“应用设置 → 数据与存储”先提供数据位置、占用与引用、缓存管理、备份/恢复、数据导入导出及受控清理入口；复用 Q02 的引用/lease/外部文件政策和既有迁移工具。恢复前核对 schema/插件兼容及停写条件，未知 schema 不写入；清理展示将删除的对象、在途引用和不可逆性，不能把卸载、删记录、删源件、删外部成品合成一个按钮。缓存与持久记录/资源分开标识，不能仅因文件暂时未显示就判作可删缓存。数据导入导出用于存储维护，项目文件/译文导出和结果下载仍在项目或结果页。原件只读，恢复失败保留备份及诊断。完整数据库浏览/编辑、共享权限和多库产品化另分切片。

## 项目导入与预检推荐

导入先问目标：解析/识别、术语候选、翻译或特定产物，容器格式与实际内容类型分开。先本地检查文本层、图片和布局，展示原生/扫描/漫画/混合页的依据、采样页及不确定性；仅在用户许可时用轻量模型辅助，不默认上传私有整本资料。混合内容允许按页/范围调整。

推荐列出真实已注册能力、所需资源、输入输出兼容性、理由和可编辑参数；缺件、未验证重建或不兼容 binding 明示，不能因扩展名为 PDF 强制某引擎或翻译。执行前确认实际计划与外发/费用；只解析无需翻译插件、目标语言或 renderer，识别/VLM 的调用与费用独立呈现。预检失败可手动选兼容能力或保留草稿，不把推荐器作为纯解析必需依赖。

## 跨页交互与界面语言

普通翻译、资源管理、设置、任务及项目页共用最低交互要求：主要动作和恢复操作可用键盘完成，焦点顺序及弹层关闭后的返回明确；控件、错误和状态有可读名称，读屏可获知变化；窄屏/缩放保留内容及确认按钮，不依赖颜色或悬停传达唯一信息。

界面语言属于“通用”设置，独立于正文及翻译目标语言。实际支持语言的切换与重开保持一致；共享控件和插件贡献缺少译文时回退到明确默认文本，不显示空白或内部 key，也不改变有效翻译约束。按[跨页验收](../../plan/0.1.x/validation/cross-cutting.md#跨页交互与语言)记录已测页面/语言及辅助技术环境；新增语言和复杂编辑器再扩展，不先建完整国际化专项。
