| --- | --- |

[ADR-0002](../decisions/0002-plugin-composition-0.1.0.md)保留已采纳的组合原则；[ADR-0001](../decisions/0001-runtime-selection.md)保存早期运行时决策与实验依据。新活跃计划和设计统一按目标软件 `0.1.x` 组织，原 [design-v3](../plan/follow-ups/design-v3.md) 作为稳定事项 ID 保留，不新建并行的 v3 文档编号体系。

判断“现在能做什么”看[能力表](../plan/0.1.0/capabilities.md)和相应用户指南；判断“接下来做什么”看 [0.1.x 工作包](../plan/0.1.x/work-packages.md)；判断“过去验证了什么”看有日期及提交的[阶段记录](../plan/0.1.0/README.md)。三者不互相替代。

维护时保留原需求 ID、章节锚点和固定提交证据，不为整理目录改写历史报告。改变当前协议必须在同一实施 PR 中更新代码、测试、兼容说明与对应文档；规划目录变化本身不修改 `API_VERSION` 或持久化 schema。
