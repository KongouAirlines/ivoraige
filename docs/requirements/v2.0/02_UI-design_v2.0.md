## 1. 设计约束与目标

| 约束 | 落实 |
|---|---|
| 深色/浅色主题可切换 | CSS 变量双主题 + 用户偏好持久化，见 §3 |
| 左侧功能栏 | 上方：主页与各功能入口；下方：账户与设置，见 §2 |
| 主区域依插件而定 | 每个功能插件注册自己的主区页面，见 §4 的页面注册机制 |
| PDF 自动处理页 | 处理设置、流程进度、性能/token 消耗摘要、PDF 预览，见 §5.2 |
| 文本翻译页 | 仿 DeepL 双栏风格，支持重新生成，见 §5.3 |
| 三端一致 | 同一 SPA 构建产物，无平台分支；由浏览器渲染，无原生组件 |

技术取向：静态 SPA，构建期打进内核单文件；框架选 **React**（与 DSH client 组件同生态，后续若复用 `dsh-client-ui-settings` 等页面组件无框架转换成本）；样式用 CSS 变量 + 普通 CSS 模块，不引入 Tailwind 等运行时方案；PDF 预览用 PDF.js（v1.0 候选池已有）。状态管理用轻量方案（zustand 或等价），不上 Redux。

### 2.1 左侧功能栏

- 宽度 216px，可折叠为 56px 纯图标（折叠状态本地持久化）。
- **上半区（功能导航，纵向排列）**：主页、文档、文本翻译、PDF 处理、术语、任务。顺序即上表；功能插件注册新页面时追加到此区。
- **下半区（钉底）**：账户、设置。与功能区之间分隔线，视觉权重降低一级。
- 当前页高亮：左侧 3px 强调色条 + 背景色块；键盘 `Ctrl/Cmd+1..9` 直达。
- 徽章：任务项显示运行中任务数；某功能有待确认事项（如待确认术语候选数）显示数字徽章。

### 2.2 顶栏

- 左：当前页面标题与面包屑（如"PDF 处理 / 某论文.pdf"）。
- 右：主题切换（太阳/月亮图标，单击循环 浅色→深色→跟随系统）、全局任务指示器（有运行中任务时显示旋转点，点击跳任务页）、内核连接状态（SSE 断连时红色标记 + 自动重连提示）。

### 2.3 路由

前端路由 `#/` 开头，避免与后端 API 路径冲突：

| 路由 | 页面 |
|---|---|
| `#/` | 主页 |
| `#/documents` / `#/documents/:docId` | 文档列表 / 文档详情 |
| `#/translate` | 文本翻译 |
| `#/pdf` / `#/pdf/:taskId` | PDF 处理 |
| `#/terms` | 术语 |
| `#/tasks` / `#/tasks/:taskId` | 任务 |
| `#/workbench/:docId` | 精翻工作台 |
| `#/account` | 账户 |
| `#/settings` | 独立设置窗口，进入首个已注册页面 |
| `#/settings/models` | 模型列表；`?provider=…&model=…` 定位编辑项，`?new=1` 添加 |
| `#/settings/pdf` | 已装配 PDF 插件的组件状态与配置指引 |

刷新后路由保持；SSE 重连后按当前路由重新订阅对应任务。

## 3. 主题系统

双主题，CSS 变量实现，无运行时换肤框架。

### 3.1 机制

- `:root[data-theme="light"]` 与 `:root[data-theme="dark"]` 各定义一套变量；组件只引用变量，不写死色值。
- 三态偏好：`light | dark | system`，存 `localStorage["ivoraige.theme"]`；`system` 监听 `prefers-color-scheme` 变化。
- 切换即时生效（改 `data-theme` 属性），无闪烁：入口 HTML 内联一段启动脚本，在首帧前读 localStorage 设置 `data-theme`。
- 后端不存主题偏好（纯客户端状态）；账户体系若未来引入再同步。

### 3.2 变量约定（最小集合）

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg-base` | `#ffffff` | `#16181d` | 主区背景 |
| `--bg-raised` | `#f5f6f8` | `#1e2128` | 卡片、侧栏、面板 |
| `--bg-sunken` | `#eceef1` | `#101216` | 输入区、对照原文区 |
| `--fg-primary` | `#1a1d23` | `#e8eaee` | 正文 |
| `--fg-secondary` | `#5b6270` | `#9aa1ad` | 次要文字 |
| `--accent` | `#2f6fde` | `#5b8def` | 链接、主按钮、高亮条 |
| `--border` | `#d9dce1` | `#30343d` | 分隔线 |
| `--ok` / `--warn` / `--err` | 语义色各一 | 语义色各一（提高亮度） | 任务状态、校验提示 |

状态色（运行中/成功/失败/取消）用语义变量，不直写颜色名；色盲可辨：状态同时以图标+文字表达，不只靠颜色。

### 3.3 字体与密度

- 正文：系统字体栈（`-apple-system, "Segoe UI", "Noto Sans CJK SC", sans-serif`）；原文/译文对照区允许用户在设置中指定衬线字体。
- 等宽：`ui-monospace` 栈，用于 token 数、ID、JSON 展示。
- 基准字号 14px，设置页提供 紧凑/标准/宽松 三档密度（影响行高与卡片间距）。

## 4. 主区域：插件页面注册机制

主区域内容"依据不同插件而定"落实为前端的**页面注册表**，与后端插件一一对应：

```ts
interface FeaturePage {
  id: string;                    // 与后端插件服务名一致
  title: string;                 // 侧栏显示名
  icon: Icon;
  route: string;                 // 路由前缀
  navSection: 'features';        // 功能入口一律进功能区；账户/设置是壳固有项
  component: React.ComponentType; // 主区组件
  badge?: () => number | null;   // 可选数字徽章
}
```

- 壳（布局、主题、路由、SSE 连接、任务指示器）不含业务；业务页面组件按注册表挂载。
- 后端某插件未启用时，对应页面不注册，侧栏不显示该入口——侧栏内容因此天然反映当前部署能力。
- 页面间跳转一律走路由（如 PDF 任务完成 → "在工作台中打开"跳 `#/workbench/:docId`），不做跨页面内部引用。

## 5. 页面设计

### 5.1 主页

- 最近文档（卡片：标题、格式、状态、各输出有无）。
- 运行中任务横条（进度条 + 取消按钮）。
- 快捷入口：导入文件（拖拽区）、新建文本翻译。
- 用量概览：近 7 日模型调用次数与 token 消耗（数据来源同 §5.2.3，未知标"未知"，沿用后端不填零规则）。

### 5.2 PDF 处理页

对应后端 `parse`/`translation`/`export` 管线与 `Task` 事件。四个区块，自上而下：

#### 5.2.1 处理设置区（顶部卡片，可折叠）

- 输入：文件拖拽/选择；来源标识（sourceId）可选填。
- 翻译方案（profile）下拉：模型分工、词库组合、风格；与设置页方案管理联动。
- 处理选项：页码范围、输出格式勾选（译文 PDF／双语 PDF／Markdown／JSON）、翻译模式（快速=自动接受／精细=草稿进工作台）。
- 同次勾选的多个出口提交为一个 outputs 列表，共用后端返回的 snapshotId；任务期间编辑不改变这批输出，重新按当前译文导出时创建新快照。
- "开始处理"按钮；已有该文档任务时按钮变"查看任务"。

#### 5.2.2 流程进度区

- 阶段条：解析 → 翻译 → 输出，三段，各自 进行中/完成/失败 状态；当前阶段显示百分比与已处理单位数（如"翻译 142/388 段"）。
- SSE 订阅 `task/{id}` 事件流驱动；断线重连后拉一次 `GET` 快照对齐。
- 操作：取消、暂停/恢复（后端 textTask 能力直达）。
- 失败时：红标阶段 + 错误摘要 + "跳到出错位置"（有 unitId 时跳工作台对应段）。

#### 5.2.3 性能与 token 消耗摘要区

| 指标 | 来源 | 展示规则 |
|---|---|---|
| 各阶段耗时 | Task 事件时间戳 | 解析/翻译/输出分列 |
| 模型调用次数 | Task 事件计数 | 区分初译与复用命中（如"调用 96 次，复用 292 段"） |
| token 用量 | LLM 层 usage | 按模型角色分（建库/正文/审校）；**usage 未知显示"未知"，不显示 0**（后端硬规则，前端照做） |
| 复用率 | 派生：复用单位数/总可译单位数 | 百分比 |

任务结束后摘要持久展示（从 Task 记录读，非仅存在于实时流）。

#### 5.2.4 PDF 预览区

- PDF.js 渲染；左右双栏可切换：原文 | 译文、原文 | 双语对照。
- 与进度联动：预览页脚显示"对应单位：#142"；点击预览中的段落高亮对应 unit（解析器提供 locator 时）。
- 输出格式多于 PDF 时，预览区顶部 tab 切换文件。

### 5.3 文本翻译页（仿 DeepL 风格）

```
┌─────────────────────┬─────────────────────┐
│ 源语言 [自动检测▾]   │ 目标语言 [中文▾]     │
│  ┌───────────────┐  │  ┌───────────────┐  │
│  │               │  │  │               │  │
│  │  输入原文       │  │  │  译文           │  │
│  │               │  │  │  [重新生成]      │  │
│  └───────────────┘  │  └───────────────┘  │
│  字数统计 · 清空      │  复制 · 换方案重译    │
└─────────────────────┴─────────────────────┘
```

行为细节：

- 输入防抖（500ms）自动翻译；可关闭改为手动按钮（设置项）。
- **重新生成**：同一原文再调一次，产出新 Revision（`origin: machine`），译文区显示版本箭头（◀ 1/3 ▶）可在多次生成间翻看；接受其一才写 accepted。
- 换方案重译：切换 profile 后一键重译，同样保留历史版本。
- 术语命中标记：译文中命中的已确认术语下划线，悬浮显示术语条目与来源库。
- 输出区右上角：复制按钮；"送入工作台"链接（直接打开文本入口已返回的 documentId，不二次导入）；版本历史按 unitId 和 targetLang 查询，刷新后仍可恢复。
- 字数统计与 token 消耗显示在译文区底栏，小字次要色。
- 语言方向快捷交换按钮（⇄），中译学术英场景常用。

### 5.4 精翻工作台页

三栏：

- **左栏（单位列表）**：虚拟滚动；每段显示原文首行 + 状态点（未译/草稿/已接受/已修改）；筛选器：全部/未译/草稿/已接受；框选多段发起"范围翻译"。
- **中栏（对照编辑）**：当前段原文在上（sunken 底色、只读），译文编辑框在下；下方版本历史（machine/human 修订列表，接受/回退按钮）；快捷键：`Ctrl+Enter` 接受并跳下一段，`Ctrl+R` 重译本段。
- **右栏（上下文）**：命中术语、前后段对照、来源定位（页码/段落）；可折叠。

翻译粒度触发：单段按钮 / 左栏框选后"翻译所选" / 顶栏"翻译全文"——三者调同一后端方法，前端只是构造不同的 unitIds 列表。

查询、翻译和编辑均传当前 targetLang；写草稿用 baseRevisionId，接受／回退用 expectedAcceptedRevisionId，具体语义以 [API 协议 §1.4／§3.2](03_API-protocol_v2.0.md) 为准。编辑先保存草稿，接受后才进入新的导出清单；原先已启动的输出继续使用原冻结清单。

### 5.5 文档、术语、任务页

- **文档列表**：表格（标题、格式、来源、单位数、任务状态、产物）；行内操作：打开工作台、导出、构建 RAG。
- **术语页**：左库树（共享库/项目库），右条目表（原文、译名、状态、适用范围）；候选确认工作区置顶。字段展示随词库结构研判调整，前端只按 schema 渲染。
- **任务页**：全量任务表（种类、文档、状态、进度、耗时）；行内取消/恢复；点击进详情（同 §5.2.2/§5.2.3 的进度与摘要组件复用）。

### 5.6 账户与设置页（侧栏下半区）

- **账户页**：各模型提供商凭据的状态列表（已配置/缺失/失效），不显示秘密本体；跳转到设置的对应凭据项。多设备/多用户未启用前，此页主要是凭据健康面板。
- **设置窗口**：桌面采用大型对话框，窄屏全屏，独立侧边栏由已装配插件贡献；打开窗口保持后台业务页及未保存编辑挂载。复用 DSH settings/config-editor 的 profile 与热更新约定，模型和凭据使用显式保存，离开未保存编辑须确认；保存中阻止退出，冲突或部分保存后重读核对。关闭与 Escape 返回背景页并恢复焦点；直接进入设置时背景为主页。
- **0.1.0 页面范围**：模型页提供列表及模型／提供商／凭据分类编辑；PDF 页读取组件状态并提供准备指引，未装配不出现，已装配但不可用仍保留说明。组件状态刷新不触发处理、安装或下载。翻译方案、词库组合、界面密度和存储管理等后续页面由对应插件实现后注册，不预留空入口。PDF 启动配置仍从文件读取，修改须重启，不在窗口中编辑可执行命令。

## 6. 前端工程

### 6.1 构建与打包

- 构建产物为纯静态文件（`dist/`：一个 HTML + 若干 hashed JS/CSS），构建期嵌入内核单文件（SEA blob 资源）或旁置 assets 目录（体积策略见后端文档 §11）。
- 开发期：前端 dev server 代理 `/api`、`/sse` 到本地内核；生产期由内核 `serve` 直接吐静态字节。
- 无 SSR、无服务端模板。

### 6.2 数据与状态

- 服务端状态（文档、任务、术语）一律经 REST 拉取 + SSE 增量，前端不缓存派生副本到 localStorage（主题、侧栏折叠等纯 UI 偏好除外）。
- 全局 store 只放：连接状态、主题、当前运行任务摘要、路由。页面数据组件级自管。
- SSE 断线：指数退避重连（1s→30s 上限），重连成功拉快照对齐；顶栏连接指示器全程可见。

### 6.3 可访问性与键盘

- 全站键盘可达；§2.1 导航快捷键 + §5.4 工作台快捷键为首批。
- 对比度按 WCAG AA 选色；状态不只靠颜色（§3.2）。
- 语言：界面首版中文，文案走 i18n 表，不硬编码字符串。

### 6.4 测试口径

- 组件级：主题切换无闪烁、SSE 重连对齐、版本翻看组件、token"未知"展示规则。
- 端到端冒烟：三主用例（导入 PDF 看进度与预览、文本翻译重新生成、工作台逐段接受）在浏览器自动化中跑通；三端由后端 serve 一致性保证，前端不重复做平台矩阵。

## 7. 与后端文档的边界

- 本文只定义界面结构、交互与前端工程；接口字段、任务模型、存储规则以《设计与验收基线 v2.0》为准。
- 页面注册表（§4）的 `id` 与后端插件服务名一致，是唯一耦合点；新增功能 = 后端加插件 + 前端加一条注册。
- 词库相关页面（§5.5）随词库结构研判结果调整，本文不锁定字段。

### Q02 retention state in the task view

The task view labels `abandoned` as `已放弃`, provides a filter for that terminal state, and offers an explicit `放弃任务` action only for failed tasks. The action preserves the failure detail and updates the list. The Web UI refreshes on `task.abandoned` as on other terminal task events. Artifact record deletion and managed file cleanup remain available through CLI, HTTP and MCP; the Web UI does not imply that a task abandonment deletes an artifact or file.
