# M4：个人使用完善

用户已选择简化 CLI 作为最小使用形态。跳过拟议的 M3.2，沿用 [M3.1](../m3.1/README.md) 已完成的模块边界，收尾 MVP；不继续以排版精修或自动质量策略作为前置。

## 最小范围

1. 复用 JSON 配置保存模型、存储位置及常用任务选项，命令行可明确覆盖；密钥仍从环境变量读取。
2. 简化文本任务操作和状态查看，允许显式批量选定有效草稿，复用现有记录、任务和输出服务；重新运行不无故重译。
3. 写明首次安装、文本流程、PDF 快照导入与回放、失败后继续处理的命令，以及当前能力边界。

显式批量选定表示用户选择输出版本，不表示逐条人工审阅或新建了自动科学质量判定。无效或过期内容仍按既有逻辑处理；不靠改变核心校验来通过这次验收。

## 完成条件

- 用原创文本和模拟模型验证简化入口、配置复用、持久化与导出；同一有效接受版本再次运行不产生正文调用。
- 失败状态、缺少译文和取消可见，已有接受译文不被静默覆盖。
- PDF 沿用已有工程验收证据；若修改 CLI 调用，验证受影响的接口，不重复运行整批科学语料。
- 文档与实际命令一致，保存完成记录并创建本地提交。

## 留给 MVP 后

自动版本选定策略、占位符合理重排、pdf2zh-next 排版对照、Web UI、外部词典、术语库结构完善和第二个真实解析器均为后续工作。本阶段不新增通用插件市场、完整可视化工作流或独立组件发布体系。具体建议见[总结](../retrospective.md)与[pdf2zh-next 源码参考](../../../research/pdf2zh-next-mvp-reference.md)。
