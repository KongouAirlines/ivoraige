## 插件作者阅读路径

从 [P05](packages/foundation.md#p05) 和[服务/资源所有权](../../requirements/0.1.x/contracts.md#cordis-服务插件与资源所有权对照)开始，按能力读[适配器契约](../../requirements/0.1.x/contracts.md#解析翻译输出三份独立契约)，再读[包清单与安装](migration-distribution.md#插件包与安装)、V04/V04a 及[npm 准备](../0.1.0/npm-readiness.md)。涉及引擎/原生资源时加读 P08 的实际依赖、许可证通知、对应源码/构建材料关系；作者按既有矩阵提供证据，不只提交 manifest 中的 license 字段。

## 决策方式

切片启动时由维护者确认责任角色的认领和最小输入，将具体执行纳入既有工作包或按去重规则登记。范围变动只改 releases，验收证据只回写执行索引。只有出现需要长期保留理由的真实架构取舍（如信任模型、持久兼容或分发边界变化）才补 ADR；字段澄清和阅读导航无需为数量新增 ADR。
