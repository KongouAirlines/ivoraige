### 延迟复制候选间隙

迭代搜索仍存在预算未覆盖的复制成本：每遇到一个锚点，旧实现会立即复制 `source[cursor:found]`。若长前缀之后有许多重复锚点，而后续必需锚点缺失，回溯会重复复制同一长前缀。安全计数夹具使用 10,000 字符前缀和 200 个晚锚点，在修复前记录 200 次切片、累计 2,019,900 个字符；无需构造巨大字符串或施加内存压力即可复现。

路径现在只保存源字符串的 `(start, end)` 范围，在完整搜索证明唯一且未耗尽预算后才复制接受结果。DFS 探索顺序、候选上限、保守搜索字符预算、歧义检测及 payload／字面 token 回退保持不变。只复制最终互不重叠的间隙，累计复制字符不超过源字符串长度；旧来源绑定和冻结快照格式不变。

计数回归验证死路、第二个完整解及两类预算在首解后耗尽均不切片；唯一解按预期范围生成文本。新增用例先失败，再在修复后通过。固定种子 780190 的 100,000 组原创输入对比修改前后的映射结果和警告完全一致，包含空/重复锚点、payload、歧义及候选/搜索字符预算边界；这是对本轮迭代实现改动的差分，不替代历史递归算法证据。
