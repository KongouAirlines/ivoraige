# 0.1.0 PDF 预试排几何与字号

候选分支 `fix/0.1.x-pdf-layout-fit-plan` 基于 #78 的 `fe055149`；不包含 #73/#74 的模型边界或 #79 的工作台选择修复。

## 原创复现与修复

BabelDOC 0.6.4 预试排可在临时扩大的框内找到合适比例，但只保存比例。正式排版从原框起步，失败后先减小一级，再扩大框，造成额外缩小。`test_layout_engine.py` 使用已安装的固定引擎实际排版方法、PyMuPDF 内置 Helvetica 和原创英文标题：框宽70、高24，允许向下扩到-20时，基线预试排约0.70、正式约0.65。

适配层仅保存原引擎已成功的框与比例。正式排版前检查原框未变、比例未受全文策略改变，且扩框仍满足引擎当前可用空间及边距；通过后复用该框，再调用原引擎 fit。发生阻挡、几何变化或比例变化则走原方法。没有强制字号、不跳过溢出检查，也不复制一个平行排版算法。钩子限定在单次 sidecar 引擎调用内，结束或异常时恢复原方法。

新捕获在 `captureConfig.layoutFitPolicy` 固定 `fit-box-v1`，捕获和回放按该标记选择策略。旧绑定缺少标记时保留原方法，不升级或重写既有绑定、译文和快照。未知标记拒绝回放。协议、绑定 schema 和外部引擎版本不变；此标记是捕获配置身份的一部分。独立 PDF 组件的源码包同时携带适配模块；构建脚本拒绝无法确认包含新策略的旧PyInstaller产物复用，需完整重建。
