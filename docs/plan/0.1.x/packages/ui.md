# 普通翻译与管理 UI工作包

[执行索引](../work-packages.md) · [领域契约](../../../requirements/0.1.x/ui.md) · [验证索引](../validation.md)

## U01

按 [普通翻译设计](../../../requirements/0.1.x/ui.md#独立普通文本翻译)交付独立页面、候选修订交互及转项目接点。

- 不做：不强制项目/工作流，不默认收费或自动接受，不等待新项目 schema 才能编辑。
- 验收：[U01 专项](../validation/ui.md#u01)，并通过 [U-V01](../validation.md#u-v01)。
- 回退：按页面切回兼容入口，保留修订和草稿；关闭新增模型动作，不删除历史或改写 accepted。

独立普通页不等待 W02 项目、W04 画布或 D05 桌面；仅转项目接点在 W02 就绪后启用。

## U02

按 [三层归属](../../../requirements/0.1.x/ui.md#三层归属与设置标签)交付导航、设置、同源模型/连接管理与插件管理切片；旧配置/深链接入兼容层。

- 不做：不建市场、第二配置库或连接基础设施，不按插件数量增加设置标签，不做空功能菜单。
- 验收：[U02 专项](../validation/ui.md#u02)，并通过 [U-V02](../validation.md#u-v02)。
- 回退：页面可回退；旧模型/连接身份与关系保留；配置结构变化须备份/双读，卸载不删用户数据。

## U03

按 [资源与数据管理](../../../requirements/0.1.x/ui.md#术语知识库与数据管理)及[预检设计](../../../requirements/0.1.x/ui.md#项目导入与预检推荐)分别交付术语、存储设置和推荐。

- 不做：不承诺完整共享权限、数据库直接编辑或默认外发；推荐不阻塞手动纯解析。
- 验收：[U03 专项](../validation/ui.md#u03)，并通过 [U-V03](../validation.md#u-v03)。
- 回退：禁用新入口保留库/备份/项目选择；退回手动兼容操作，不能以降版声称恢复已清理数据。
