复核是源码静态阅读及 GitHub 元数据读取，没有执行本地业务单测、模型、真实 PDF、故障注入、安装或性能验收。既有 [main CI run 39255702238](https://github.com/KongouAirlines/ivoraige/actions/runs/39255702238) 在 Windows/Ubuntu/macOS Node 24 成功，包含 Python sidecar、归档审计夹具、Node tests 和 package smoke；不外推真实安装器、PDF 排版、模型质量或历史 tag。固定 DSH `639ed015` 内 Cordis 为 4.0.4；jobs owner 经 live session 解析为 Agent，无 owner 共用 unowned 槽，wait 超时返回当前视图。

基线仓库已有 22 个远端分支、0 个打开 PR 的审计快照；本地历史工作树不能替代 main。PR #31/#32 的审计及许可内容已合入，旧 Release/附件撤下，当前源码优先；这些变化不修复旧实物。当前安全报告、问题模板和导航已使用 canonical 仓库名 ivoraige；固定历史证据中的 ivaraige 拼写保留，不据旧拼写推定运行故障或安排全量历史刷新。
