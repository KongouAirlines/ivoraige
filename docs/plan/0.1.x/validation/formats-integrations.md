## 格式与软件协作

按[支线路线](../formats-integrations.md)分别记录提取、草稿和原生回写，不用单个“支持”勾选覆盖全部。固定样本、adapterId/版本、目标应用/客户端版本、命令和人工检查范围；尚未支持结构要显式列出。

| ID / 工作包 | 最小证据 |
| --- | --- |
| F-V01 / F01 | DOCX 正文/标题/列表/普通表格，跨 run、字段与超链接边界、非文字内容；新副本打开无修复提示与视觉抽查分别通过。页眉脚注/文本框/批注修订/公式嵌入对象支持策略可见 |
| F-V02 / F02 | 无 DRM 可重排 EPUB 多章节、manifest/spine/nav/CSS/图片/脚注锚点完整，EPUBCheck 与阅读器视觉分别检查；字体混淆不误判 DRM，受限内容不绕过 |
| F-V03 / F03 | PPTX 页/形状定位、master/layout/theme/notes 关系、长译文溢出/裁切警告与人工路径；不无限缩字或声称图表/SmartArt 自动无损 |
| F-V04 / F04 | XLSX 选区内同 shared string 不同语境可不同译文，未选内容/公式/数值/日期/工作表名不改；等号开头译文保持文本，宏/外链不执行 |
| I-V01 / I01 | Zotero 选定条目/附件导入、源版本关联、明确确认后新产物附回；重复请求/响应丢失查询无重复附件，不改原件；外部删除/更新/权限变更显式诊断 |
| I-V02 / I02 | 固定 KISS/Pot 候选版本选文输入/返回结果；Umi-OCR 只识别可结束。认证、Origin、取消/断开、重复提交、任务关联和未安装降级成立 |
| I-V03 / I03 | Markdown/电子书文件与资源交接只触及选定目标；相对链接、幂等、外部修改冲突和新副本策略可核对；不暗开双向同步或自动上传 |

各格式还须通过原件只读、畸形/越界包、解压资源限额、未知 schema、缺插件/绑定及最终包闭包检查；“能打开”与内容/视觉正确性分开。桥接共享来源/文件交接/方案/状态取消/产物/权限错误契约，不通过暴露宽权限端口取巧。功能日程按依赖/阶段管理，不以本表约定日期。

## 工作包专项验收

### F01

F-V01 提取/草稿/原生分别验收，打开无修复提示、视觉抽检及原件不变。

### F02

F-V02 EPUBCheck 与阅读器抽查分开，章节/脚注/资源引用保持，源文件不覆盖。

### F03

F-V03 提取和输出分别合格；shape/slide 关联与 master/layout/theme/notes 保留；溢出提示。

### F04

F-V04 未选单元格/公式/数值/日期不变，等号译文仍为文本；源件不覆盖。

### I01

I-V01 只读→显式确认写回，超时查询/重复请求无重复附件，原件保留、外部变更可诊断。

### I02

I-V02 身份/认证/取消/断开、识别无需翻译、重复提交、内容不串任务。

### I03

I-V03 明确目标目录/资源相对链接、重复交换/外部改动冲突、用户确认与新文件策略。
