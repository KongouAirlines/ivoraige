## 格式与软件协作

按[支线路线](../formats-integrations.md)分别记录提取、草稿和原生回写，不用单个“支持”勾选覆盖全部。固定样本、adapterId/版本、目标应用/客户端版本、命令和人工检查范围；尚未支持结构要显式列出。

| ID / 工作包 | 最小证据 |
| --- | --- |
| F-V01 / F01 | DOCX 正文/标题/列表/普通表格，跨 run、字段与超链接边界、非文字内容；新副本打开无修复提示与视觉抽查分别通过。页眉脚注/文本框/批注修订/公式嵌入对象支持策略可见 |
| F-V02 / F02 | 无 DRM 可重排 EPUB 多章节、manifest/spine/nav/CSS/图片/脚注锚点完整，EPUBCheck 与阅读器视觉分别检查；字体混淆不误判 DRM，受限内容不绕过 |
| F-V03 / F03 | PPTX 页/形状定位、master/layout/theme/notes 关系、长译文溢出/裁切警告与人工路径；不无限缩字或声称图表/SmartArt 自动无损 |
| F-V04 / F04 | XLSX 选区内同 shared string 不同语境可不同译文，未选内容/公式/数值/日期/工作表名不改；等号开头译文保持文本，宏/外链不执行 |
| I-V01 / I01 | 分别登记 [I-V01.shared](#i-v01-shared)、[I-V01.callable](#i-v01-callable)、[I-V01.zotero](#i-v01-zotero) 的版本化证据。共用 API 只发现授权方案；已发布修订和每次运行冻结一致，并发方案不串模型/术语配置，客户端不能提升允许覆盖范围，取消/错误及缺件明确。Zotero 高优先切片独立验收：选定条目/附件导入、源版本关联、明确确认后新产物附回；重复请求/响应丢失查询无重复附件，不改原件；外部删除/更新/权限变更显式诊断 |
| I-V02 / I02 | KT 端到端前置为 I01.shared@1 / I01.callable@1 的通过证据，不依赖整个 I01。固定支持插件的 KT 版本：单段/HTML、批次 ID 对齐、术语冲突、取消、截断流及客户端重装；不将 dev 能力推定为商店版已有。后续 Pot/Umi-OCR 各自验收，OCR 可只识别结束。认证、Origin、取消/断开、重复提交、任务关联和未安装降级成立 |
| I-V03 / I03 | Markdown/电子书文件与资源交接只触及选定目标；相对链接、幂等、外部修改冲突和新副本策略可核对；不暗开双向同步或自动上传 |

各格式还须通过原件只读、畸形/越界包、解压资源限额、未知 schema、缺插件/绑定及最终包闭包检查；“能打开”与内容/视觉正确性分开。桥接共享来源/文件交接/方案/状态取消/产物/权限错误契约，不通过暴露宽权限端口取巧。功能日程按依赖/阶段管理，不以本表约定日期。

## 工作包专项验收

### F01

F-V01 提取/草稿/原生分别验收，打开无修复提示、视觉抽检及原件不变。

### F02

F-V02 EPUBCheck 与阅读器抽查分开，章节/脚注/资源引用保持，源文件不覆盖。

### F03

F-V03 提取和输出分别合格；shape/slide 关联与 master/layout/theme/notes 保留；溢出提示。

### F04

F-V04 未选单元格/公式/数值/日期不变，等号译文仍为文本；源件不覆盖。

### I01

I-V01 按以下子验收登记证据，对应[具名子交付](../packages/formats-integrations.md#共享子交付)。每份证据记录实际契约版本、实现提交、命令/样本、通过与未测项；未完成的 Zotero/OpenAI 等切片不阻塞已通过共享切片被 I02 使用。

<a id="i-v01-shared"></a>

#### I-V01.shared

I01.shared@1 满足[单机授权](../../../requirements/0.1.x/contracts.md#单机客户端授权)：owner 批准/签发/撤销和只展示一次的秘密处理可验证；两个 principal 即使调用同一方案也不能读/取消对方任务。HTTP 与 MCP 分别运行拒绝矩阵：

| 场景 | 必须观察到的结果 |
| --- | --- |
| 无凭据、伪造/过期/撤销凭据；仅自报 clientId 或无 Origin | 401 或等价机器错误，无业务副作用 |
| 有效凭据缺 operation、方案、术语写 scope，或访问别人的任务/结果/产物/事件 | 403 或等价错误，不因对象存在与否泄漏差异；发现列表不含无权方案 |
| 有效凭据但 Origin 不符；尝试宽权限内部工具/owner 参数/旧匿名路由 | 明确拒绝；旧 HTTP/MCP、事件、下载均无旁路；门禁失败时不能启动外部模式 |
| 撤销后排队调度、流重连、幂等重试、取消/读取已有任务 | 按撤销契约拒绝；在途取消有状态/未知供应商副作用证据，不把冻结快照当永久授权 |
| 合法 principal、operation、范围、Origin/原生凭据组合 | 仅获准操作成功；获准范围内缺对象为 404；日志/错误不含秘密 |

本机 stdio 探针同时验证宿主绑定身份，客户端名称不能升级为 owner；上游模型/Zotero key 不能用作入站凭据。端到端证据不能只用伪造授权上下文的单元测试替代。

<a id="i-v01-callable"></a>

#### I-V01.callable

引用 I01.shared@1、W02 保存冻结与 [U03.terms@1](ui.md#u-v03-terms) 的通过证据。W03/U02 UI 未安装时，owner 用受控 CLI 调同一后端发布/描述/撤下方案，客户端可执行已发布版本；覆盖越界拒绝，并发方案不串模型/词库。库/抽取配置版本、有效约束与允许覆盖值进入运行快照；默认修改不改旧运行，权限撤销仍即时生效。选库缺能力或声明抽取却缺 termBuilder 时明确失败。不得仅靠 UI 截图或 mock 词库宣称完成。

<a id="i-v01-zotero"></a>

#### I-V01.zotero

引用 I01.shared@1 及 P02/P03 来源/资源证据；选定条目/附件只读导入、版本关联与显式确认后新产物附回分开验收。超时查询/重复请求无重复附件，原件保留、外部变更可诊断；若本切片调用翻译方案再引用 I-V01.callable。KT 或 OpenAI 未交付时仍可完成此切片，不能仅以客户端名称或 Zotero 上游 key 授权。

### I02

I-V02 记录 I01.shared@1/I01.callable@1（含 U03.terms@1）的实际版本和 I-V01.shared/I-V01.callable 通过证据，再在固定 KT 插件版本运行同一授权拒绝矩阵及单段/HTML、批次、术语冲突、取消/截断流探针。W03.publish-ui@1、I01.zotero@1、OpenAI 未安装时仍可完成；配置由 owner CLI 准备，不由客户端改变全局模型。后续 OCR 切片可仅依赖 I01.shared@1 与解析能力，不能机械要求翻译方案。

### I03

I-V03 明确目标目录/资源相对链接、重复交换/外部改动冲突、用户确认与新文件策略。
