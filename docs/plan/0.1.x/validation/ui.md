# 普通翻译与管理 UI验证

[验证索引](../validation.md) · [工作包](../packages/ui.md)

## 独立普通翻译与管理 UI

按 [UI 草案](../../../requirements/0.1.x/ui.md)分别验收普通页、全局导航和项目内步骤检查；U01–U03 的每个切片提交实现、交互测试与相应用户文档，不用截图或后端安装 smoke 代替交互证据。无模型场景用离线夹具，模型请求用可控延迟/乱序 mock；真实外发另有授权及用途记录。

### U-V01 普通翻译

按 [普通页设计](../../../requirements/0.1.x/ui.md#独立普通文本翻译)验证无项目输入、双栏/窄屏、无模型手动编辑及键盘/读屏操作；本次参数可就近调整，继承来源/清除覆盖/有效值可核对。

选词、选句、全文动作的实际请求范围分别核验，候选差异/拒绝/采纳/撤回可用。覆盖请求后编辑、换语言/约束、取消、响应乱序和多单元选区，过期结果不得覆盖新稿；采纳不自动 accepted 或入术语库，并发接受冲突可见，已有冻结输出不变。默认输入零模型调用，费用/外发及未知 usage 可见。W02 接线后，转项目保留文档/修订历史且零再翻译。

### U-V02 导航管理与设置

按 [导航表](../../../requirements/0.1.x/ui.md#全局导航与主页)和[五类设置](../../../requirements/0.1.x/ui.md#三层归属与设置标签)逐项核对入口；折叠资源组后任务入口/数量仍可见，窄屏保留内容主区，步骤检查不冒充导航。未交付能力无假菜单，已有缺插件项目仍可查看历史、诊断及修复；数据与存储稳定入口随实际管理能力启用，不用占位页通过验收。

| 验证面 | 必需案例与证据 |
| --- | --- |
| 同一模型/连接管理器 | 模型页和设置入口编辑同一对象；添加模型可选择/新建连接，两个模型共享连接时移除一个不删连接。连接变更/删除展示引用影响，提供方插件、连接、模型身份不混淆；旧配置/深链迁移保留身份、未保存编辑及回退证据 |
| 有效配置与授权 | 全局默认、项目及本次覆盖可追溯，清除覆盖恢复继承；改默认不抹掉显式值或修改在途/历史定义。连接变更不暗扩授权，旧运行恢复不换模型；超时/重试默认不突破宿主限制，不对未知远端结果盲重试。显式测试费用/外发可见，刷新不生成 |
| 插件操作与恢复 | 发现/安装、资源准备、更新、启停、卸载、专属配置逐项覆盖成功/中断/失败；安装/启用/就绪分开，在途任务阻止危险卸载。卸载保留用户数据，第二同类插件不要求核心菜单名单变更，无 UI 仍可恢复 |
| 页面迁移与单一来源 | 验证插件操作/高级配置、全局策略、本次参数各归设计位置，同一配置不产生双来源；PDF 资源迁出 settings/pdf，项目文件/译文导出和结果下载仍在项目/结果页，旧深链定位原记录或修复说明 |

### U-V03 资源数据与预检

按 [资源/数据设计](../../../requirements/0.1.x/ui.md#术语知识库与数据管理)与[预检设计](../../../requirements/0.1.x/ui.md#项目导入与预检推荐)分三项记录交付范围和未交付项。

| 验证面 | 必需案例与证据 |
| --- | --- |
| 术语候选与库 | 候选显示来源/含义并显式入库，项目挂载、自动复用、外发独立；作用域先于优先级，旧修订/快照不随库更新改写 |
| 存储维护 | 设置子页稳定可达，位置/占用/引用可核对，缓存与持久数据分开。数据导入导出/备份恢复验证 schema、停写和失败；活动 lease 阻止清理，原件及外部文件政策可见 |
| 预检推荐 | 容器与内容分开，原生/扫描/混合页有依据和采样范围；推荐可改且只用真实能力。缺件/重建不兼容明确，手动纯解析无翻译或目标语言依赖；不暗传私有全文，识别费用单列 |

完整共享权限和数据库编辑不在本轮承诺。W-V03 继续验证项目内容上下文，不能替代 U-V01 独立普通页。
