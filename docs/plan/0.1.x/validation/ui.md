# 普通翻译与管理 UI验证

[验证索引](../validation.md) · [工作包](../packages/ui.md)

## 独立普通翻译与管理 UI

按 [UI 草案](../../../requirements/0.1.x/ui.md)分别验收普通页、全局导航和项目内步骤检查；U01–U03 的每个切片提交实现、交互测试与相应用户文档，不用截图或后端安装 smoke 代替交互证据。无模型场景用离线夹具，模型请求用可控延迟/乱序 mock；真实外发另有授权及用途记录。

各实际页面同时检查[跨页交互与语言](cross-cutting.md#跨页交互与语言)及相关[安全与诊断](cross-cutting.md#安全与诊断)。

### U-V01 普通翻译

按 [普通页设计](../../../requirements/0.1.x/ui.md#独立普通文本翻译)验证无项目输入、双栏/窄屏、无模型手动编辑及键盘/读屏操作；本次参数可就近调整，继承来源/清除覆盖/有效值可核对。

选词、选句、全文动作的实际请求范围分别核验，候选差异/拒绝/采纳/撤回可用。覆盖请求后编辑、换语言/约束、取消、响应乱序和多单元选区，过期结果不得覆盖新稿；采纳不自动 accepted 或入术语库，并发接受冲突可见，已有冻结输出不变。默认关闭自动预览时，输入/编辑/保存零模型调用；用户明确开启预览后只调用独立指定的已配置模型；云端预览启用前须说明自动传输输入及可能计费并取得明确选择，正式翻译/精译须明确点击，费用/外发及未知 usage 可见。W02 接线后，转项目保留文档/修订历史且零再翻译。

实际生成/重写能力另按[译文质量框架](cross-cutting.md#质量分层与译文评审)给出人工评审和比较基线，交互 mock 通过不能代替质量结论。

<a id="本地预览验收"></a>
#### 即时预览验收

按[预览设计](../../../requirements/0.1.x/ui.md#可选即时预览)执行以下矩阵；本表是待实施验收，不是已测结果。记录源码提交、所选模型/连接身份、有效参数、服务与客户端环境及输入约束，不记录凭据。可控 mock 核验调用目标和顺序；实际质量与时延另以固定输入测试，不能由 mock 推定。

| 验证面 | 必需案例与证据 |
| --- | --- |
| 默认与触发 | 默认关闭时连续键入/粘贴/编辑/保存均零调用，选择预览模型也不自动启用；明确开启后暂停输入才触发。输入法 composition 期间零触发，结束后重新防抖；分别记录最后输入到提交、提交到完成及最后输入到可见结果的时延，不能用防抖数值代替完成时延 |
| 独立配置与不可用 | 正式翻译模型已配置但预览模型未指定时仍暂停且零调用；两者可选不同模型，修改正式默认不改变预览选择。覆盖连接不可达、鉴权失败、模型不可用、不支持语种和调用失败，显示原因并保留可编辑内容；核对请求记录，不调用其他本地/云端或正式翻译模型，配置修复不暗换目标 |
| 云端启用与发送范围 | 所选服务、输入及必要上下文范围、自动传输和可能计费在启用前可见；未确认/取消时零调用，明确启用后防抖请求只发往所选连接且不超展示范围。更换模型/连接或扩大范围先暂停并重新取得对应启用选择；正式翻译/精译仍须点击。关闭后无新调用，取消不伪报远端停止或零费用，未知 usage 保持未知；诊断不外发正文 |
| 取消与结果保护 | 可控延迟/乱序夹具覆盖新输入、清空、语言/约束/模型变化、关闭开关及页面切换；取消不支持或未及时完成时仍丢弃旧结果。请求中人工编辑或接受后，预览不能覆盖译稿/accepted；显式采纳只产生新修订，接受仍需并发检查，冻结输出不变 |
| 手动配置与本地服务 | 不依赖 #39 的发现/状态辅助，手动配置连接可用于预览；本地服务由用户运行，应用不下载/加载/卸载模型或管理 GPU/服务。选用本地连接时核对实际调用目标及请求记录，不能静默改发云端；本地服务停止时暂停预览，手动编辑仍可用 |
| 时延与质量 | 对实际选用的模型/连接记录短句与段落样本长度、约束、重复次数及端到端时延分布，区分服务就绪/启动和网络条件；用合规中英双向样本人工检查术语、数字/单位、否定、混排、漏译与段落连贯性。模型能力、低时延或 mock 通过均不能替代质量证据，不承诺固定响应时间 |

预览未交付时单列该切片未通过，不能把普通页验收当作预览验收。内置引擎/语言包和 #39 均不作为本矩阵前置。

##### 远期内置路线的附加评估

仅在未来选择[本地候选](../local-translation-preview.md#远期可选内置引擎与语言包)时另行验证：模型/语言包版本与摘要、量化格式、运行引擎及参数；来源/许可/大小提示、确认下载、取消/断网/完整性校验与恢复；准备后离线推理，联网时预览正文不上传，下载请求不携带正文。缺包或失败不得自动下载无关模型或回退其他模型。

资源评估覆盖普通 Windows x64 轻薄本 CPU 与 Apple Silicon Mac，记录 OS/CPU/RAM/架构和电源模式，区分冷/热启动、短句/段落，报告重复次数、端到端 p50/p95、峰值内存及引擎/权重/完整语言包的下载和落盘大小。人工对照专用与通用模型，量化/非量化分列；通用模型检查关闭思考且只输出译文。其他平台列明未测，先以质量与资源结果讨论门槛，不将上游支持列表或候选表视为实机结论。

### U-V02 导航管理与设置

按 [导航表](../../../requirements/0.1.x/ui.md#全局导航与主页)和[五类设置](../../../requirements/0.1.x/ui.md#三层归属与设置标签)逐项核对入口；折叠资源组后任务入口/数量仍可见，窄屏保留内容主区，步骤检查不冒充导航。未交付能力无假菜单，已有缺插件项目仍可查看历史、诊断及修复；数据与存储稳定入口随实际管理能力启用，不用占位页通过验收。

| 验证面 | 必需案例与证据 |
| --- | --- |
| 同一模型/连接管理器 | 模型页和设置入口编辑同一对象；添加模型可选择/新建连接，两个模型共享连接时移除一个不删连接。连接变更/删除展示引用影响，提供方插件、连接、模型身份不混淆；旧配置/深链迁移保留身份、未保存编辑及回退证据 |
| 有效配置与授权 | 全局默认、项目及本次覆盖可追溯，清除覆盖恢复继承；改默认不抹掉显式值或修改在途/历史定义。连接变更不暗扩授权，旧运行恢复不换模型；超时/重试默认不突破宿主限制，不对未知远端结果盲重试。显式测试费用/外发可见，刷新不生成 |
| 插件操作与恢复 | 发现/安装、资源准备、更新、启停、卸载、专属配置逐项覆盖成功/中断/失败；安装/启用/就绪分开，在途任务阻止危险卸载。卸载保留用户数据，第二同类插件不要求核心菜单名单变更，无 UI 仍可恢复 |
| 页面迁移与单一来源 | 验证插件操作/高级配置、全局策略、本次参数各归设计位置，同一配置不产生双来源；PDF 资源迁出 settings/pdf，项目文件/译文导出和结果下载仍在项目/结果页，旧深链定位原记录或修复说明 |

### U-V03 资源数据与预检

按 [资源/数据设计](../../../requirements/0.1.x/ui.md#术语知识库与数据管理)与[预检设计](../../../requirements/0.1.x/ui.md#项目导入与预检推荐)分三项记录交付范围和未交付项。

| 验证面 | 必需案例与证据 |
| --- | --- |
| 术语候选与库 | 先通过[后端双来源及复用验收](cross-cutting.md#术语与复用)，再检查候选显示来源/含义并显式入库，项目挂载、自动复用、外发独立；作用域先于优先级，旧修订/快照不随库更新改写 |
| 存储维护 | 设置子页稳定可达，位置/占用/引用可核对，缓存与持久数据分开。数据导入导出/备份恢复验证 schema、停写和失败；活动 lease 阻止清理，原件及外部文件政策可见 |
| 预检推荐 | 容器与内容分开，原生/扫描/混合页有依据和采样范围；推荐可改且只用真实能力。缺件/重建不兼容明确，手动纯解析无翻译或目标语言依赖；不暗传私有全文，识别费用单列 |

完整共享权限和数据库编辑不在本轮承诺。W-V03 继续验证项目内容上下文，不能替代 U-V01 独立普通页。
