# 跨领域最小验收

[领域覆盖](../domains.md)关联承接包；以下案例随实际交付能力执行，并把证据写回原工作包。基础契约/纯解析只执行相关检查，完整评测平台不是其前置。

## 术语与复用

U03 术语切片先按[术语契约](../../../requirements/0.1.x/contracts.md#术语服务与翻译复用)验证后端，再用 U-V03 验证管理界面。沿用[补充 0001](../../../requirements/amendments/0001-term-applicability.md#后续实现参考当前不执行)的 H field 两来源控制文本：书内专用义项只在适用来源生效，另一来源不被同词形或项目库优先污染；通用/适用领域术语仍可复用。

检查候选确认、共享库中专用项、冲突显式呈现、范围/来源导入导出及版本变化。改范围仅使相关结果需复核，历史 accepted/冻结快照不变；缺少身份或旧版本信息时不得猜测通用性。术语能力缺席时，无术语组合仍可用；明确选择术语约束却无法装配时须诊断失败，不能静默当作未选择。

## 质量分层与译文评审

| 结论 | 单独的观察对象与依据 |
| --- | --- |
| 解析质量 | units、阅读顺序、表格/公式/图片及来源完整性，见 [V05](../validation.md#v05) 和 [PDF 案例](pdf.md#数据pdf-与分发) |
| 译文质量 | 原文到候选/人工修订的语义、完整性及适用术语，按下述最小记录；解析成功或界面操作正确不能代替它 |
| 重建质量 | 已冻结译文到最终文件的缺漏、版面、公式及顺序，见 [P09/P10](pdf.md#p09)；固定同一译文比较，零新增翻译调用 |

实际翻译能力交付或模型/约束语义改变时，至少提供：

- **样本类别与用途**：覆盖该切片声称支持的语言/方向及内容，例如普通短文、含否定/数字/歧义的句段、领域术语文本、长段上下文；局部替换/重写另含选区和上下文边界。只声称测过的类别，公开/合成与私有样本的用途、外发许可分别记录。
- **比较基线**：固定原文/来源版本、此前可复现的模型配置或人工确认参考；新能力没有历史基线时如实说明，建立首个参考结果，不虚报提升。比较输入和约束一致，重复运行的波动单列。
- **人工判据**：逐项检查忠实性（否定、条件、数值、关系及无依据增补）、漏译/重复、按来源范围成立的术语一致性；可读性和局部重写是否越过指定意图另记。保留问题片段、类别、严重程度、理由和人工修正，自动分数只作辅助。
- **版本与证据**：记录实际模型/提供商、可获版本、生成参数、提示/约束及术语版本、样本修订、候选与人工接受关系、usage/成本或未知值、运行环境与评审者角色；秘密和无权公开的正文不进入公开结果。
- **切片结论**：实施 PR 在评价前说明样本选择、通过判据和可接受范围；具体数值阈值随用途确定，列出通过/失败/未测及剩余限制。不能等完整评测工程才验收实际翻译，也不能把“质量后续”作为永久豁免。

单测/mock 验证协议和修订保护；模型输出的人工判断另附实际证据。导出与重建只消费 accepted 冻结数据，沿用 [V01](../validation.md#v01) 的模型不可达和零调用护栏。

## 安全与诊断

按[信任边界](../../../requirements/0.1.x/contracts.md#安全隐私与诊断边界)选择所交付路径；每例记录入口、资源/能力范围、预期拒绝或恢复结果和脱敏证据。

| 边界 | 最小检查 |
| --- | --- |
| 本地 HTTP/MCP 与文件入口 | 非预期 Host/Origin、未获授权调用/外发、越界路径及错误资源归属被拒绝；未安装入口不监听。MCP 接入不能被描述为独立沙箱或完整多用户授权 |
| 插件与 sidecar | 缺件/不兼容/启动失败/执行崩溃可定位插件、版本及阶段，卸载/取消不清除用户历史；检查实际传入环境、凭据引用、文件和网络范围，输出边界不得持有模型/凭据 |
| 模型提供商与日志 | 请求只含获准内容/用途；响应、错误、诊断导出及事件中无凭据或无权披露的私有正文。执行未知不伪报零调用，不盲重试收费操作 |
| 数据保留与故障恢复 | 区分持久记录、草稿、资源和缓存，按 Q02/迁移矩阵检查引用及清理。任务卡住/取消超时/插件失活时，记录关联 task/operation/component、失败阶段、安全原因及可采取的恢复动作；重启后仍可查权威状态 |

复用现有错误/traceId、任务和组件状态；需要补关联字段时在 P04/P05 的协议中固定，不另建 tracing 服务。当前暴露须随相关切片检查，远程/共享需求只触发更完整的数据流与权限审查。

## 跨页交互与语言

对交付的普通翻译、资源管理、设置、任务及项目页分别抽查主要操作与失败恢复；沿用 [UI 最低线](../../../requirements/0.1.x/ui.md#跨页交互与界面语言)：键盘可到达并完成动作、焦点顺序/返回可预期，读屏可识别控件及状态，窄屏/缩放不丢内容和确认按钮，错误不只靠颜色或悬停。

对实际支持的界面语言验证切换、保存/重开、共享控件和插件贡献字符串；缺失翻译及不支持的持久语言设置回退到明确的默认文本，不显示空白或内部 key。切换界面语言不改正文、目标语言、术语约束或在途运行。记录浏览器/辅助技术与未测组合，不将某一页可用外推为整个 UI 已验收。
