## 桌面验证

[桌面完整方案](../desktop.md) 规定 B0/B1、B2/B3、U1/U2/U3、J1、P1、R1、F1、Q1 场景、全进程树归因、原始数据和建议预算。其 D1/W1/W2/P1/D2/D3 只作为输入拆分名称，执行状态统一映射至本计划 D01/D02/D03/D04/D05，不再独立跟踪。

先测当前 host/browser，再比较两个可行壳候选。必须验证 UI 销毁前草稿持久化确认、任务不中断、进程后代回收、worker 空闲停止可重启、应用退出与窗口关闭不同、断线快照恢复。没有性能测量时不能选定资源预算，也不能宣传轻量。

三系统分别提供 native 证据：Windows 进程树/锁/退出；macOS 最后窗口与 Quit；Linux 明确桌面环境、X11/Wayland、托盘缺席降级。内核 CI 不替代原生托盘或 GPU 验收。显存、唤醒等不可测项写 unknown/未测，禁止填零；共享外部模型服务不能被当作本应用 worker 杀掉。

## 工作包专项验收

### D01

fixture 覆盖二次启动、断线、任务暂停/取消/强制退出、后代进程归属和重启；能力按任务类型声明。

### D02

最后确认日志恢复；保存失败不销毁 UI；明确 debounce 损失窗口；并发基修订冲突显式呈现。

### D03

同一 WebUI 浏览器/候选壳使用；订阅/定时器释放；同样数据减少无关查询且状态一致。

### D04

[桌面方案](../desktop.md) 的 manifest/CSV/actions/trace；不可测项明确，指标按平台口径。

### D05

三平台 native smoke 与关闭/退出/恢复/故障矩阵；没有 native 证据不宣称支持。
