## 工作流与内容工作台

细节见[工作流契约](../../../requirements/0.1.x/workflows.md)。历史导入翻译导出测试不能代替组合执行证据。

| ID / 工作包 | 动作与通过条件 | 不可据此宣称 |
| --- | --- | --- |
| W-V01 / W01 | 默认链通过组合定义执行，实际插件跑至少两个真实不同拓扑：纯结构化建库/输出、同能力不同参数的分支汇合/人工决定后输出；增删/替换和目标选择改变执行计划而无需改宿主阶段名单。类型/schema/单集合错误、循环、缺插件拒绝；取消/清理沿用 tasks/jobs，导出零翻译 | 只有固定分支开关、图形演示或 mock 声明就算组合；最小建库样例是完整 RAG |
| W-V02 / W02 | 保存/另存/版本化实例与脱敏模板，重开后连接/参数完整；运行冻结定义，状态仍可更新。人工决定生成后续片段；修改上游只让相关下游待更新，旧成功保留、已接受成果不覆盖。目标输出仅跑必要依赖；模型未知执行、上传响应丢失、幂等重试与能力不支持恢复均有显式路径 | 任意调用 exactly-once、同模型逐字重现、所有操作可暂停/缓存/恢复 |
| W-V03 / W03 | 内容主区与轻状态条；折叠侧栏/编排模式切换后文件/页码/选段/草稿恢复，普通翻译无需项目/画布。保存失败不销毁；过期人工决定要求重核；键盘/小窗口可用 | 未确认保存的全部编辑可崩溃恢复，浏览器检查替代 native |
| W-V04 / W04 | 同一分支/汇合定义经卡片→图→卡片保存重开无丢失；简版无法表示时只读/提示仍保留数据；并发编辑冲突明确，选择节点不触发执行/批准 | 已支持循环/任意脚本或另一个图执行器 |

旧记录迁移夹具必须保留内容、任务、修订/产物身份，缺失的历史输入快照/血缘标未知；旧配置生成的是新草稿。证据还需覆盖模板中私有路径/凭据/用户内容不泄漏、取消只清理本次资源、外部结果未知时不盲目重复付费/上传。全图重跑不能绕过现有 applicability、接受并发检查和 `ExportSnapshot` 护栏。

## 工作包专项验收

### W01

W-V01 至少两种真实拓扑、同能力不同参数、分支汇合、人工后续片段；类型错/缺件拒绝；不硬编码流程名单。

### W02

W-V02 模板无秘密、可调用方案只引用保存定义且改版不改旧运行、冻结定义与可变状态分离、人工后续片段、局部失效、不重复写回、旧历史不伪造血缘。

### W03

W-V03 保留文件/页码/选段/草稿，模式切换不丢分支；键盘/小屏可用；保存失败不销毁。

<a id="w-v03-publish-ui"></a>

#### W-V03.publish-ui

I01.callable@1 已通过本机受控 CLI 的发布/撤回与冻结验收后，验证 W03.publish-ui@1 的列表/表单与 CLI 编辑同一配置；版本冲突、允许覆盖、测试费用/外发、撤回和键盘操作明确。UI 不可用不影响已发布方案的授权调用，也不产生第二配置来源。

### W04

W-V04 卡片/图往返与并发定义冲突，复杂结构无法简显时保留并提示；节点选择不等于运行或批准。
