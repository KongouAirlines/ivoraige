# 0.1.x 验证矩阵

这是验收设计，不是通过记录。工作包状态见 [唯一表](work-packages.md)。实施时记录 commit、环境、输入版本、命令、实际结果、未测项和恢复动作；历史 0.1.0 测试不自动算成 0.1.x 证据。

## 基础验证链

| ID / 阶段 | 最小组合与动作 | 通过条件 | 不能据此宣称 |

原文输出与翻译输出分别设置 golden fixtures；零调用同时以未装翻译服务、模型调用计数和输出依赖边界证明，不只检查界面按钮。output handler 不接收 ctx/service locator，并检查传入值不能间接携带模型或凭据。缺件测试覆盖：未安装、禁用、缺资源、版本不兼容、启动失败、执行中崩溃、取消、超时、重启；保留已保存修订和冻结产物。

已有 `test/export.test.mjs` 包含 data-only、未绑定 this、冻结不可写和无 LLM 服务断言；本轮目标是保留并按异步 signal/新插件增强。Q01 覆盖导出冲突不增快照；Q02 覆盖 failed 任务放弃、artifact 删除与活动 lease；Q03 覆盖非法 settings 值/JSON/缺件的三入口错误。P01/P05 还需双向安装/业务配额交错和无响应 wait 总截止期，不能将资源饱和记录为模型失败。当前 MCP 已有 component_status 测试调用，后续补完整 settings/组件注册及失败矩阵。

### V03 状态同步竞态

按[同步契约](../../requirements/0.1.x/contracts.md#状态快照与订阅的同步边界)用可控提交/握手/快照屏障测试，不能靠 sleep 碰运气。记录 generation、scope、barrier、快照 revision 和通知投递次序；这是后续 P04/D01/D03 的验收要求，本轮没有运行协议实现。

| 调度 / 故障 | 必须证明 |
| --- | --- |
| 任务恰在旧的“snapshot 返回后、订阅生效前”窗口完成，此后无新事件 | 旧读取结果不能直接作为已同步视图；先完成订阅握手再重新取快照，完成状态要么已在快照内，要么由缓冲通知触发重取，不依赖未来事件唤醒 |
| 任务分别在订阅安装边界前/后、就绪响应传输中、快照读取/响应中完成，此后无新事件 | 每个提交要么由一致快照覆盖，要么可靠失效通知；最终状态与后端一致，不能用发送端时间戳猜测顺序 |
| 收到 > r 通知，重取快照时再次完成另一任务，此后无新事件 | 同一有效订阅持续缓冲，第二次变化也被快照或再次失效覆盖；重取不能重新引入订阅空窗 |
| 重复/延迟通知、过滤导致 revision 跳号、scope 变化 | 同 generation/scope 下 ≤ r 通知可忽略，> r 失效；跳号本身不等于丢包，scope 变化重新握手，不交叉比较 |
| host 重启、断线、缓冲溢出或显式 resync-required | 丢弃旧 generation/订阅的同步资格，新握手后重取；有限缓冲、合并/退避和关闭清理有效；状态静止后收敛，不需要持久事件重放 |

## 数据、PDF 与分发

迁移按 [兼容矩阵](migration-distribution.md) 执行：旧库/快照只读和升级、同根重启、数据根搬迁、重导入身份、公式/上下文改变拒绝误复用、未知 schema 拒绝写、部分失败恢复。记录与 checkpoint 原子提交、并发接受版本检查不因重构削弱。

PDF 分三个独立结论：

- P06 解析质量：结构、阅读顺序、公式/表格/图片与资源恢复。解析成功不保证排版成功。
- P09 同引擎重建：相同人工确认译文，分别走各自兼容 renderer，逐页检查缺漏、公式损坏、顺序、溢出、缩字与分页，记录耗时/资源/失败；冻结重放零翻译。BabelDOC 保留对照，不预定默认替换。
- P10 跨引擎重建：独立 many-to-many binding 映射，明确哪些结构可映射、哪些需人工确认/拒绝；不因都叫 PDF 跳过兼容判断。该验收失败不阻塞已通过的纯解析。

普通 CI 用公开合规/合成夹具及离线 mock；真实文档和模型按已有授权及 [#13](https://github.com/KongouAirlines/ivoraige/issues/13) 来源用途规则执行。样本选择覆盖短原生 PDF、双栏、公式、表格、长中文译文；扫描/OCR 另列，不把原生 PDF 结果推广。完整私有样本库、科研质量评测和风格学习不是基础接口的前置。

P08 从最终归档检查依赖和许可，再做无 `.git` 源码归档/干净主体/独立插件安装 smoke；源码或 mock 成功不能称实际安装包已验收。未装 PDF 时主体无需 Python，安装 PDF 不得变相安装翻译必需配置。

## 桌面验证

[桌面完整方案](desktop.md) 规定 B0/B1、B2/B3、U1/U2/U3、J1、P1、R1、F1、Q1 场景、全进程树归因、原始数据和建议预算。其 D1/W1/W2/P1/D2/D3 只作为输入拆分名称，执行状态统一映射至本计划 D01/D02/D03/D04/D05，不再独立跟踪。

先测当前 host/browser，再比较两个可行壳候选。必须验证 UI 销毁前草稿持久化确认、任务不中断、进程后代回收、worker 空闲停止可重启、应用退出与窗口关闭不同、断线快照恢复。没有性能测量时不能选定资源预算，也不能宣传轻量。

三系统分别提供 native 证据：Windows 进程树/锁/退出；macOS 最后窗口与 Quit；Linux 明确桌面环境、X11/Wayland、托盘缺席降级。内核 CI 不替代原生托盘或 GPU 验收。显存、唤醒等不可测项写 unknown/未测，禁止填零；共享外部模型服务不能被当作本应用 worker 杀掉。
