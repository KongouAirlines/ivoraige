# 0.1.0 设置窗口使用

本页对应 `0.1.0` 源码及自行构建的 npm 包。目前不提供预构建下载包；原默认 PDF Release 已撤下，在线查询无法取得该版本，本机已有组件可继续使用。

## 打开与返回保护

- 从工作台左侧栏点击“设置”即可打开独立设置窗口（桌面端左侧为设置导航，窄屏顶部排列页面入口）。
- 点击关闭按钮或按 `Escape` 返回原页面时，会完整保留当前所选段落、目标语言、未保存的译文草稿，以及 PDF 单位的来源页码与勾选状态（注：“页码保留”指保留所选单位的来源页码定位，不代表内嵌 PDF 阅读器）。直接通过 `#/settings/models` 或 `#/settings/pdf` 打开时，关闭将返回主页。
- 离开存在未保存修改的模型编辑表单、关闭窗口或点击浏览器返回时，窗口会提示“继续编辑”或“放弃修改”；浏览器刷新或关闭标签页时也会触发原生未保存提示。正在保存时请等待结果返回后再离开。

## 模型、提供商与凭据

模型页展示已保存的模型列表与当前生效的翻译模型。点击“添加模型”可选择内置预设，也可在列表中点击“查看／编辑”。编辑表单按三层分组：

- **模型**：模型 ID、请求超时与上下文容量（留空字段按内置目录继承默认值）。
- **提供商**：同一提供商标识共享的端点 URL、API 类型与推理参数，并列出受该路由影响的模型。
- **凭据**：API Key 独立保存，读取设置时只显示凭据状态，从不回显密钥明文。

保存与切换规则：

- **仅保存**：保存配置修改，维持原翻译模型选择不变。
- **保存并用于翻译**：保存配置并立即切换为当前翻译模型。
- **用于翻译**（列表操作）：仅在已保存模型之间切换当前选择。
- 保存配置或切换模型不会自动启动翻译任务；修改设置前须先暂停运行中或排队中的翻译任务。逐单位翻译的提示词模板目前通过 CLI 和共享 operation 管理，不在此设置窗口编辑，详见[提示词库使用说明](prompt-library-guide.md)。

## 参数校验与并发冲突处理

- **保存前参数校验**：模型设置中的 `compat`（兼容开关）和 `reasoningEfforts`（推理强度）若包含无效值，会在保存前直接报参数错误；其中 `compat` 开关必须适用于该路由中至少一个模型实际使用的协议（含继承或内置目录确定的协议）。设置组件缺失时返回明确的组件错误。
- **CLI 设置校验**：CLI `settings --set` 若传入格式错误的 JSON 或非对象根值（如 `null`、数组），在本地和远程模式下均返回 `INVALID_ARGUMENT`，退出码为 `2`。
- **并发与部分写入恢复**：发生 revision 冲突，或提供商路由已写入但模型列表写入失败时，表单会保留当前输入并阻止重复提交；点击“重新读取设置”需先确认放弃未保存输入，随后读取实际落库配置供核对。若凭据写入成功但后续状态刷新失败，界面会分别提示，且不会保留已提交的密钥明文等待重试。

## PDF 组件与动态插件设置页

- **PDF 组件管理**：当 PDF 组件安装管理或 PDF 能力已装配时，设置导航会显示“PDF”入口。
  - 启用安装管理的构建可在此查询版本、安装、取消和重试（支持公开源匿名访问，仓库令牌仅在访问私有源或需要授权额度时配置，步骤见[安装指南](installation-guide.md)）。
  - 可显式点击“移除已保存令牌”切回匿名访问，且不会丢弃输入框中尚未保存的替换令牌；通过启动环境变量传入的凭据需在启动环境中移除。
  - 状态展示区分“已配置，首次处理时验证”与“已验证”；点击“刷新状态”仅读取当前配置状态，首次导入或导出 PDF 时才会实际验证 Python 引擎与资产。仅挂载已有 PDF 配置、未启用安装管理的服务只显示状态与指引。安装完成后请保存工作并重启服务。缺少 PDF 组件时，文本工作台和模型设置仍可正常使用（PDF 操作见 [PDF 指南](pdf-guide.md)）。
- **插件热刷新与卸载保护**：插件挂载或卸载会通过 SSE 实时刷新设置导航，断线重连后重新读取实际能力。若当前正在编辑的插件被卸载，表单会禁用提交并清空凭据输入，同时暂留非秘密草稿供核对；确认离开后可切换到其他设置页。无任何插件贡献设置页时显示空状态。实现与验证边界见源码仓库中的 `docs/plan/0.1.0/settings-dsh.md` 和 `settings-goal.md`。
