# 0.1.0 设置窗口使用

从工作台侧栏点击“设置”，打开独立窗口。桌面左侧是设置导航，窄屏顶部排列页面入口。关闭按钮或 Escape 返回原页面，保留选段、目标语言及未保存译文；PDF 单位的来源页码与勾选也保留。直接打开 `#/settings/models` 或 `#/settings/pdf` 时，关闭返回主页。

模型页先显示已保存列表及当前翻译模型。点击“添加模型”选择预设，或在列表中“查看／编辑”。内层按“模型”“提供商”“凭据”分组：模型包括 ID、超时和容量；提供商包括共享端点、API 和推理参数，并列出受影响模型；凭据输入独立保存且不会回显密钥。配置字段留空继承目录默认的规则与此前一致。

“仅保存”保存配置，维持原翻译模型选择；“保存并用于翻译”同时切换当前模型。列表中的“用于翻译”仅切换已保存选择。保存与选择不会自动启动翻译。修改设置前仍须暂停运行或排队的翻译任务。

离开未保存模型编辑、关闭窗口或浏览器返回时，窗口会提供“继续编辑”和“放弃修改”。浏览器刷新／关闭还有原生未保存提示。保存中等待结果后再离开。发生 revision 冲突或路由已写入而模型列表写入失败时，表单保留输入并阻止重复提交；“重新读取设置”需确认放弃未保存输入，再读取实际配置供核对。凭据写入成功、后续状态刷新失败会分别提示；不会保留已提交的密钥等待重试。

PDF 组件安装管理或 PDF 能力已装配时显示“PDF”入口。启用安装管理的发行包可以在此授权发布源、查询版本、安装、取消和重试；具体步骤见[安装指南](installation-guide.md)。安装完成后保存工作并重启服务。状态区分配置就绪和实际验证结果；“刷新状态”只读取现状，首次导入或导出才验证引擎与资产。仅挂载已有 PDF 配置、未启用安装管理的服务只提供状态与指引。使用步骤见 [PDF 指南](pdf-guide.md)；缺少 PDF 组件时文本和模型设置仍可使用。

插件挂载／卸载经 SSE 刷新设置导航；重连重新读取实际能力。正在编辑的插件卸载后，提交禁用、凭据输入清空，非秘密草稿暂留以供核对，确认离开后可选其他页面。没有插件贡献设置页时显示空状态。

实现与验证边界见源码仓库中的 `docs/plan/0.1.0/settings-dsh.md` 和 `settings-goal.md`。PDF 的“页码保留”指现有工作台所选单位的来源页码，不代表新增了内嵌 PDF 阅读器。
