# Markdown 文本工作台阶段

Markdown 来源适配器读取 `.md`／`.markdown` 或显式 `format: 'md'`／`'markdown'`。输出沿用现有冻结快照，按导入时记录的原文偏移替换已接受的可译文本。未替换部分直接复制原文，因此换行、缩进、围栏、代码、数学公式、链接目标和图片路径保持原有字符。输出阶段只读取快照，不调用模型。

当前有意限定为可确认来源绑定的子集：ATX 标题、单行段落、单行有序／无序列表、单行引用、围栏／缩进代码、独立 `$$` 数学块，以及行内代码、`$…$` 数学、内联链接和图片、配对的强调标记。代码与整块数学作为不可译单位；行内保护内容跳过，可译文字按源位置拆成单位。图片替代文字可译，目标路径不变。修订文字按 Markdown 普通文本转义，且须为非空单行；`skip`／`keepOriginal` 逐字保留原文。

文件首行的 YAML front matter 以 `---` 开始，以独占一行的 `---` 或 `...` 结束，支持 UTF-8 BOM。头部须是有效 YAML 映射或空文档，只校验语法和顶层类型，不解释或执行配置，不翻译标题、摘要或其他值。头部作为 `other` 类型的不可译单位保留完整原文，sourceText 与 locator 范围一致；输出逐字保留头部和换行。未闭合、无效 YAML、标量或列表头部明确拒绝，避免将歧义正文静默排除翻译。

目前拒绝表格、setext 标题、HTML／角括号自动链接、引用式链接、裸 URL、深层列表及其缩进续行、嵌套或不配对的强调、未闭合的代码／数学／链接，以及无法判断含义的空块标记。多行段落逐行形成单位；行内代码、数学、链接和强调两侧的短语也会拆开。这样保住语法，但会牺牲跨标记句子的翻译上下文；科学质量验收前应进一步决定是否使用经验证的占位符协议。此阶段不声称支持任意 CommonMark，也不声称多行重排后的语义等价。`.qmd` 文件扩展名及 Quarto 引用、属性等语法尚未接入，不能把 YAML 头部兼容等同于完整 Quarto 支持。

接线：装配 `MarkdownSource`；持久化入口允许 `format: 'md'` 且资源为空，记录 schema 的文档格式也允许 `md`；现有 `md` 输出在 `adapterId: 'markdown'` 时调用 `renderMarkdown(frozen)`，JSON 输出可接受同一绑定。Markdown 输出与 TXT 输出应继续共用格式 id `md`，而非注册第二个 id。直接适配器测试覆盖原文重建、翻译重建、危险修订的普通文本转义和显式拒绝边界。
