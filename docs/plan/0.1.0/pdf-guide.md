# 0.1.0 PDF 使用指南

当前支持原生文本英文 PDF → 中文单语 PDF，可从同一份接受译文导出 PDF、Markdown 和 JSON。PDF 能力由可选 BabelDOC 组件提供，未安装时仍可使用文本与 Markdown。

## 开始前

按[安装指南](installation-guide.md)打开工作台，在“设置 → PDF”安装 BabelDOC，安装完成后退出并重新启动程序。安装版无需另外安装 Python 或运行准备脚本。组件“已配置”表示已找到配置，首次实际处理时才验证运行环境与资产。

需要机器翻译时，在[模型设置](settings-guide.md)中保存模型与凭据。源码开发者的 Python 准备、配置文件及回归脚本另见源码仓库的 [PDF 开发参考](https://github.com/KongouAirlines/ivaraige/blob/main/docs/plan/0.1.0/pdf-development.md)。

## 导入、审校与导出

1. 在首页或文档页上传不超过 7 MiB 的原生文本英文 PDF，源语言选择 English。
2. 在任务页查看解析进度，完成后打开文档；不需要继续时可以取消。导入不支持暂停续传。
3. 目标语言选择“简体中文（zh-CN）”。精细模式保留草稿，快速模式自动接受结果；两种模式都需要按内容质量人工检查。
4. 对照来源页码、原文与译文，保存修改并接受所需修订。`zh` 与 `zh-CN` 分别保存译文；已有中文任务要选择一致的目标语言。
5. 勾选 PDF、MD、JSON 中需要的格式，导出后从“已生成文件”下载。

所选格式共享同一冻结快照。导出不再次调用模型；修改后再次从当前接受译文导出会生成新快照，已有快照保持原内容。通过 API/CLI 指定旧 `snapshotId` 可重放旧快照。

## 检查输出

- 查看来源覆盖与导出警告，并核对公式、图注、多栏和未进入翻译单元的文字。任务成功不等于每一处内容和布局都已正确。
- 公式等不可译内容通常保留原文。编辑时保留占位符及原有顺序；BabelDOC 的解析、字体或排版限制可能导致不完美的显示。
- 默认要求可译单元均有接受译文。CLI/API 的显式 skip 允许缺失部分保留原文，所有格式共享同一决定，不临时补译。
- 扫描件 OCR、双语 PDF、MinerU 跨引擎映射仍未提供；当前独立组件验收范围为 Windows x64。

## 继续工作与恢复

正常退出后重新启动，可继续使用已有文档与修订。取消导出不删除此前已经完成的格式产物。组件修复或更改配置后先重启再处理。

备份前退出程序，复制整个用户数据目录，保留数据库及旁边的 `pdf/` 目录。不要单独移动数据库或修改受管理原件。来源丢失或损坏时，可重新导入完全相同的原 PDF 以恢复本库副本；不需要重新翻译已有文档。跨版本升级和其他平台迁移需另行验证。

更多范围见[能力与限制](capabilities.md)。维护者的来源绑定、目录清理和真实样本证据保存在源码中的 [PDF 实施记录](https://github.com/KongouAirlines/ivaraige/blob/main/docs/plan/0.1.0/pdf.md)。
