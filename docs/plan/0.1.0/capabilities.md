# 0.1.0 能力与限制

本页描述 `0.1.0` 源码及自行构建的本地 npm 包；`v2.0` 是设计文档版本。此前的 Release 附件已撤下，当前从源码运行，PDF 使用 Windows 开发准备路径或已有本机组件。历史测试与版本差异见[实施记录](README.md)。

## 已合入能力与平台边界

| 能力领域 | 当前可用范围 | 主要边界 |
| --- | --- | --- |
| TXT / Markdown | 导入、翻译、人工编辑、接受修订、MD / JSON 输出 | Markdown 是已验证子集（支持文件开头有效的 YAML 映射头部原样保留，表格、内嵌 HTML 等仍拒绝）；完整科学或文学翻译质量未做系统评价 |
| PDF（可选 BabelDOC） | BabelDOC 自身捕获、受管理原件、来源页码与坐标、单语 PDF / MD / JSON 导出 | 英文→中文曾实测；中文→英文路由已实现但尚无真实引擎／Mac 视觉验收；没有扫描件 OCR、双语 PDF、跨引擎重建保证 |
| MinerU 解析与同引擎回放（实验源码包） | DSH profile 显式装配、本地 4.0.10 SDK 协议桥、完整 MiddleJson/资源保存、原文 MD/JSON/原件 PDF；严格单 span 的人工接受译文可由同一引擎冻结回放 PDF；Linux CPU/flash 原创原生与扫描样本实测 | 两个合成 PDF 不代表任意 PDF 或 OCR 质量；表格/公式有分类和文本覆盖缺口，PDF 英文字距不理想；未作 BabelDOC 同译文对照、完整安装闭包或跨平台运行验收；不自动下载权重 |
| 修订与复用 | 按语言保存草稿与接受版本，满足适用条件时零模型调用复用 | 模型调用后、落库前崩溃不能保证供应商没有执行请求；`zh` 与 `zh-CN` 为独立修订作用域 |
| 冻结导出与来源模式 | 同任务多格式共用快照，编辑不改变已有快照，导出不调用翻译模型；支持 `--content-mode source` 原文导出 | 不覆盖同名文件；格式可用性取决于已装插件与文档来源绑定 |
| 任务与产物生命周期 | 持久状态、进度、取消；翻译／导出暂停与恢复；失败任务 `abandon` 与产物记录／受管文件删除（`retain` / `delete-owned`） | PDF 导入可取消但不支持暂停续传；安装任务不续传下载；受管文件删除与清理写入会将记录存储单元升至版本 2 |
| 使用入口 | 浏览器工作台、CLI、HTTP/SSE、MCP stdio／Streamable HTTP 共享内核 | HTTP 本机回环监听；同一 SQLite 由单个内核进程持有；MCP 客户端具有该内核的编辑、设置和组件管理权限 |
| 模型与组件 | DSH 设置、凭据及模型访问；按需安装或挂载 BabelDOC | 公开组件源可匿名读取，私有源仍需显式令牌；在线模型会收到待译内容并可能计费；免费 Index-Translate 尚未专门接入 |
| 逐单位翻译提示词 | 本地模板、按模型连接与功能绑定、文档及单次覆盖、修订追溯 | 仅 CLI／共享 operation 管理；无工作台编辑页、项目设置或其他模型功能；首次保存会将记录存储单元升至版本 3；见[提示词库](prompt-library-guide.md) |
| 平台支持 | Node.js 26.13.0 内核在 Linux、macOS、Windows 运行三平台 CI（Node 24 保留运行时兼容）；旧 `v0.1.0-dev.0` Windows x64 便携包与 PDF 组件曾在 Windows Sandbox 实测 | 新版 `0.1.0` Windows 包尚未构建或验收；Linux/macOS 独立 PDF 包、完整桌面安装器仍未交付 |

## 尚未交付的规划范围

- **术语库与格式扩展**：术语库结构与装配、EPUB、Zotero、RAG、基础文件处理扩展仍为规划。当前术语适用性字段不等于可供用户使用的术语库。
- **0.1.x 拟议改造**：[0.1.x 计划](../0.1.x/README.md)中的完整独立插件安装与回滚、MinerU 更广样本质量及依赖闭包验收、第二同类插件及桌面生命周期仍是待实施目标，不计入当前已启用行为。
