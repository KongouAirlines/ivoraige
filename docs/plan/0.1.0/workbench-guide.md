# TXT／Markdown 工作台使用指南

先按[安装与首次启动指南](installation-guide.md)从源码打开工作台，随后按下述步骤完成模型配置、导入、审校与导出。更多运行方式及 VS Code 调试请看[开发指南](development-guide.md)。同一数据目录同时只运行一个内核，其他入口连接已有服务。

## 配置翻译模型与凭据

不需要机器翻译时可跳过本节，直接导入文件并人工录入译文。

1. 打开工作台左侧“设置”窗口，在“模型”页点击“添加模型”，选择“提供商预设”，核对模型 ID 后点击“保存并用于翻译”。
   - 内置预设支持 DeepSeek、Anthropic、OpenRouter、Kimi、OpenAI、硅基流动，以及本地 Ollama／llama.cpp／LM Studio。
   - 内置目录模型的协议与端点可留空以继承默认值（输入框会提示对应默认项）。
2. 切换到“凭据”分类，输入对应的 API Key 并点击“保存凭据”（设置读取只显示凭据状态，不回显密钥）。
   - 无需认证的本地模型服务可点击“填入本地占位凭据 local”再保存（这是满足当前 SDK 要求的非秘密占位值；需要认证的服务请填写实际密钥）。
   - 保存配置或凭据不会发起模型请求，只有点击翻译时才会调用模型。
3. **管理多个模型**：填写另一组配置并点击“仅保存”，可保留原翻译模型选择；在模型列表中可随时“查看／编辑”或切换“用于翻译”。
   - 同一提供商标识共享端点、凭据和路由级推理设置；不同账号或端点请使用不同标识，未收录模型使用自定义标识并填写 API 类型、URL 及实际容量。
   - 旧的显式模型配置与当前选择会自动出现在列表中。修改配置前须先暂停运行中或排队中的翻译任务。更多细节见[设置指南](settings-guide.md)与[模型配置调研](../../research/model-settings.md)；此前 [DeepSeek 显式配置示例](../../../examples/translation-deepseek.json)仍可用于程序接口。

## 导入、翻译与人工审校

1. **导入文档**：在首页或“文档”页导入自己的 TXT／Markdown，或使用原创示例 [scientific-en.txt](../../../examples/scientific-en.txt)，导入前确认原文语言（如 `English`）。
2. **启动翻译**：打开文档工作台，选择“精细 · 保留草稿”翻译全文，可在“任务”页查看实时进度。
3. **逐段审校与编辑**：回到工作台逐段对照原文与草稿，直接修改译文并接受修订：
   - **保存草稿**：点击“保存草稿”或按 `Ctrl/Cmd+S`
   - **接受译文**：点击“接受译文”或按 `Ctrl/Cmd+Enter`
   - **保存并接受（跳至下一段）**：点击“保存并接受”或按 `Ctrl/Cmd+Shift+Enter`
   - **切换段落**：按 `Alt+↑` / `Alt+↓`；重复点击当前段落会保留正在编辑的内容，切换到其他段落时若有未保存修改会提示确认（回归边界见[选择回归记录](../0.1.x/evidence/workbench-selection-0.1.0.md)）。
   - **检索与批量操作**：左侧段落列表支持按原文关键词、`#序号` 或 `p:页码` 检索，支持一键“全选”及“接受所选草稿”。
   - **占位符校验与差异对比**：若段落含 PDF 样式或公式占位符（如 `<b1>`、`</b1>`、`<f1>`），译文框上方会实时校验占位符顺序，并提供点击插入与“一键补齐缺失标记”；修订历史区可开启“对比差异”高亮查看各版本增删内容。

## 请求边界与冻结导出

- **模型请求回显保护**：模型请求仅将当前单元作为翻译目标，相邻单元仅作上下文参考。若模型完整回显内部请求 JSON，翻译任务会报错并停止，当前单元不会生成修订；请查看任务错误、检查模型后重试（普通 JSON 原文仍可正常翻译）。其他不完整回显或相邻段落混入，以及缺少跨标记语境的 Markdown 短片段，仍需在接受译文前人工核对。
- **创建冻结快照并导出**：在右侧“上下文与输出”区（窄屏先点“显示上下文与输出 →”）勾选 `MD`／`JSON`，点击“创建冻结快照并导出”，完成后从“已生成文件”下载。
  - 导出只读取已接受的修订，**绝不调用翻译模型**。
  - 若尚有未接受的可译段落，默认导出会报告前置条件错误。

## 持久化、CLI 连接与格式边界

按 `Ctrl+C` 停止服务后，使用相同的 `--store` 路径重新启动即可恢复文档、修订、任务及模型设置。服务运行期间，其他 CLI 命令需通过 `--url` 连接正在运行的服务（若不带 `--url` 会另起内核，不能与运行中的服务同时占用同一 SQLite 文件）：

```powershell
node src/cli.mjs --url http://127.0.0.1:8787 documents --json
node src/cli.mjs --url http://127.0.0.1:8787 tasks --json
```

- **Markdown 支持范围**：当前 Markdown 仅支持已明确绑定来源位置的语法子集。文件开头有效的 YAML 映射头部（含空头部）原样保留、不参与翻译；未闭合或无效头部会报导入错误。表格、内嵌 HTML 等仍会被拒绝，详情见 [Markdown 阶段记录](markdown.md)；后续 QMD 指定 YAML 字段翻译见[后续事项](../follow-ups/quarto-qmd-support.md)。
- **其他能力入口**：PDF 操作见 [PDF 使用指南](pdf-guide.md)；包含 MCP 的源码构建可通过 `/mcp` 将 AI 客户端连接到同一工作台进程（见 [MCP 指南](mcp-guide.md)）。EPUB、RAG、术语词库及非回环远程访问尚未接入当前工作台。
