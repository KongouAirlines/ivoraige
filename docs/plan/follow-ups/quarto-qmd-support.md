## 处理条件与范围

语法绑定与资源需要统一处理，超出 YAML 头部兼容修复范围；开始完整论文／QMD 导入工作时重新评估，当前尚未排期。

建议接入 `.qmd` 文件识别及各入口导入，界定 Pandoc 引用、交叉引用、块／行内属性、带编号数学、图注、代码块及可执行单元的支持矩阵。翻译与导出须保留语法绑定、引用键、编号和资源路径；外部图片、bibliography／CSL 等资源须有明确的收集或缺失处理规则。

开始前评估复用 Quarto／Pandoc 解析能力，决定元数据 title／abstract 是否可译及其重建方式。默认不执行文档代码、渲染命令或 YAML 配置；如需执行，应单独设计并获得明确授权。不能只放开扩展名或逐个忽略报错就声称完整支持。

## 验收条件

- 原创 QMD 覆盖约定语法和资源矩阵，完成导入 → 翻译／人工接受 → 冻结导出 → 重启读回。
- 未翻译内容可原样重建；译文输出保留语法和引用关系，资源缺失有明确反馈。
- CLI／HTTP／WebUI 共用同一内核结果，导出无追加模型调用。
- 真实论文仅做只读验证，不提交原文；失败项如实记录。
