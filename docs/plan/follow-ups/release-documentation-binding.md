## 问题与影响

PDF 设置页指南链接指向 main，可能随开发变化而与已安装版本不一致。当前预发布 tag 与更新后的附件源码也不完全对应，不能简单把 main 换成该 tag 就认为已解决。

## 处理条件与范围

按用户决定，在后续 MCP 等内容完成、准备发版时作为收尾工作处理；不阻塞本次安装阶段。发版前确定发行物与指南的对应方式，未来考虑拆分仓库时可进一步优化文档分发，不提前限定公开仓库或独立 Releases 方案。

## 验收条件

- 发行包中的文档入口对应实际发布的功能和源码版本，后续 main 更新不会悄然改变旧版本说明。
- 验证安装包中的入口可用，明确私有仓库访问条件；Release 说明准确标注附件来源。
- 若未来拆分仓库，保留已发布版本文档的可追溯性。
