## 验收条件

- 真实 DSH 注册页面有构建、打开／关闭及挂载／卸载证据。
- 独立窗口支持直接打开、刷新、关闭与返回，背景编辑不丢失。
- 模型管理、端点和凭据形成主从流程，旧配置兼容及运行任务互斥不回退。
- 模型与 PDF 分别贡献页面；仅 PDF 时设置入口可用，组件失败时保留状态页面，刷新不触发处理或安装。PDF 工作台背景状态得到保留。
- 动态导航、重连和晚响应不产生重复条目或覆盖新编辑。
- 键盘、焦点、主题、窄屏、相关测试与安装包验收通过；跨系统 CI 记录实际结果。
