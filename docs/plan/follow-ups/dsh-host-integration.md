# 将 ivoraige 作为 DSH 插件安装

- ID: dsh-host-integration
- 状态: 暂缓
- 实施分支／PR: 文档登记 codex/0.1.0-documentation；代码实现未安排
- 类型: 后续功能
- 发现依据: 2026-10-13 用户提出低优先级宿主集成方向；当前 main/0a185d4 已复用 DSH 基础设施，但不等于可直接安装的宿主插件
- 目标分支: main

## 问题与影响

未来希望在已有 DSH 环境中安装 ivoraige 的翻译与文件处理能力，共用宿主服务和交互入口。当前独立工作台的装配与宿主界面接口需要进一步核实。

## 处理条件与范围

低优先级探索，待 DSH 宿主接口、实际用户需求和维护成本明确时推进。现在保持插件契约与能力边界，不提前开发第二套前端或锁定重写方案。届时比较嵌入、复用、薄适配与专用前端的必要性；继续保留独立部署能力。

## 验收条件

- 安装、启用、关闭和依赖缺失遵循 DSH 生命周期与授权边界。
- 宿主入口调用相同内核，不新增平行翻译、修订、快照或凭据实现。
- 按适用范围复用宿主模型、设置、任务和存储能力，并验证用户数据归属与兼容性。
- 前端方案有实际宿主体验证据；独立工作台仍能运行，卸载不隐式删除用户文档。
