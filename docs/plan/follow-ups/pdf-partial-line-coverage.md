# PDF 部分行覆盖审计可能重复保留原文

- ID: pdf-partial-line-coverage
- 状态: 待评估
- 实施分支／PR: 未安排
- 类型: 缺陷
- 发现依据: 2026-10-08，`codex/0.1.0-pdf-formula-replay` 原创样本真实捕获，本机 `evaluation/runs/pdf-formula-0.1.0/run-4/captured.json` 与 `partial-line-source.pdf`。
- 目标分支: main

## 问题与影响

一行英文末尾被 BabelDOC 分为可译的 `...translatio` 和不可译的 `n.`；行审计又把完整原行作为 `unmapped_pdf_text` 保留。因此一个视觉源行在 IR 中同时有完整 fallback 和部分段落，可能在 MD／JSON 中重复显示原文，不能仅凭 coverage 警告称其输出一致。已观察捕获结果，尚未完成该样本的修订后多格式对照。

## 处理条件与范围

本轮处理 Issue #11 的公式 payload、映射、标点回放及进程清理，不重新设计来源覆盖分段。后续扩展解析覆盖验收时优先处理：组合多个相邻 IL 段落的空间和文本证据，只保留确实未覆盖的片段，同时保留“重叠位置但不同文本不能丢弃”的已有回归。

## 验收条件

- 真实少页样本复现部分行拆分；每段原文在单位中不重复、不遗漏。
- 重复文字、同位置不同文字、多栏及公式行不误吞。
- 接受修订后对照 PDF、Markdown、JSON，覆盖告警与实际保留内容一致。
