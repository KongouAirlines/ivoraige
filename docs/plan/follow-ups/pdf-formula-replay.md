# PDF 公式映射、payload 与冻结回放一致性

- ID: pdf-formula-replay
- 状态: 处理中
- 实施分支／PR: [codex/0.1.0-pdf-formula-replay](https://github.com/KongouAirlines/ivaraige/tree/codex/0.1.0-pdf-formula-replay)，依赖 PR #10
- 类型: 缺陷
- 发现依据: 2026-10-08，[Issue #11](https://github.com/KongouAirlines/ivaraige/issues/11)，PR #7 合并后的 `a683f9b`；回调在 tracker 完成前复制 position，丢失 payload；相邻公式映射可能持久化为 null。
- 目标分支: main

## 问题与影响

未解决的公式显示映射可以进入翻译，但旧 PDF、Markdown、JSON 导出随后失败。人工改译文不能修复来源绑定。旧回放检查把带公式的文本记为 `present=null`，没有检查其内容；BabelDOC 0.6.4 还会把连续 20 个或更多特定标点缩为一个句点，使已接受文本与 PDF 不一致。这些差异现作为带位置的警告或导出证据呈现，兼容 BabelDOC 的实际输出。

## 处理条件与范围

用户已要求接续 Issue #11。来源恢复放 PR #10；本分支处理完成后的 tracker 与位置关联、可用时的原文显示对齐、payload／字面 token 回退、来源和占位符完整性、真实 PDF 验证。不新增手工来源绑定编辑器，不扩展 OCR 或双语输出。导入／翻译前置失败、覆盖 BabelDOC 连续标点处理及以页级文本提取结果否决 PDF 的严格策略已由兼容性策略取代。

## 验收条件

- 同文字不同位置的 payload 不串位，经过 SQLite 持久化和重启保持不变。
- 相邻公式、重复锚点、富文本 token 在唯一对齐不可得时回退为 BabelDOC payload 或字面 token，并带页码、位置与 token 警告；未知映射不得替换为空。旧 null／缺失显示不阻止冻结回放。
- 原创实际公式样本通过接受／skip／三格式冻结导出／编辑后旧快照重放；导出零模型调用，逐页检查布局。
- 来源位置、原始请求及占位符顺序不匹配仍拒绝。连续标点采用 BabelDOC 的输出；公式展开文本提取未匹配时明确记录未验证和目检提示，不作为导出失败。页级文本检查不能替代位置和视觉验收。
