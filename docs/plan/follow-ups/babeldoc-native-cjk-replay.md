# BabelDOC 原样中文行的 PDF 回放缺失或乱码

- ID: babeldoc-native-cjk-replay
- 状态: 待评估
- 实施分支／PR: `codex/0.1.x-babeldoc-0.7.1` 已记录复现，未修改上游 renderer
- 类型: 缺陷
- 发现依据: 2026-11-09，基于 main `6a5e1df20437c6c3c2cfa9c10aeff17ad4724d94` 的 0.7.1 派生桥验证；[阶段证据](../0.1.x/evidence/babeldoc-0.7.1.md)。
- 目标分支: main

## 问题与影响

原创 mixed PDF 的英文正文包含中文副标题及中文结论。原件可提取这些文字，
BabelDOC 捕获也保留它们；identity 回放后两行在 PDF 缺失或乱码，文本检查
正确发出两项警告。已观察 stock 0.7.1 identity 与派生桥输出的同类缺失，
但尚未定位上游字体、CID 或写出根因，不凭文件名断言具体原因。
新接受的中文主标题与“摘要”可正常显示；四处重复英文原文的不同中文
接受译文也可正常定位。冻结回放像素相同不表示内容完整。

## 处理条件与范围

本切片迁移已移除的 callback API，不另写 PDF renderer。继续保留原文、
覆盖记录和警告，不通过拒绝整个可用文档隐藏问题。后续在官方固定源码
与原创夹具上隔离字体/CID写出原因，优先上游修复；在扩大原样 CJK 行保真
或发布保证之前重新评估。与 `pdf-partial-line-coverage` 的 fallback 重复
不同，本项关注可视 PDF 中已有原文的丢失。

## 验收条件

- 该原创 mixed 样本中文副标题和结论在 identity 与接受回放均完整可见。
- 接受文字、已有英文/中文原文、表格、公式及双栏位置不回归。
- 零模型冻结重放及旧绑定明确迁移规则保持；记录真实字体/写出根因。
