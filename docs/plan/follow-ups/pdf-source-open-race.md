## 问题与影响

Node 校验来源真实路径及摘要后，Python 稍后按路径打开。具备受管理目录写权限的本地进程可能在该间隔替换文件。当前依赖本地文件系统权限；该调用模式早于 PR #10，不代表已证实的远程攻击入口。

## 处理条件与范围

本轮仅登记，不增加重复哈希、逐次副本或跨进程文件句柄协议。重新评估触发条件是支持不可信共享目录、跨用户部署，或出现实际替换案例。届时先定义权限与并发写入契约，再选择最小实现，避免给常规导出增加不必要 I/O。

## 验收条件

- 用受控替换探针明确窗口与影响。
- 在选定信任边界下，sidecar 读取的来源与已冻结内容一致，或明确报错。
- 来源恢复、搬迁、取消与导出零模型调用保持；记录性能影响和平台限制。
