## 1. 本轮要验证的用户价值

个人科研用户对同一篇论文完成一次翻译后，可以继续生成 PDF、Markdown 和 JSON，已接受译文与人工修改不丢失；确认的术语能用于下一篇材料。用户可以指定建库模型、翻译模型和词库，并看到进度、取消及失败位置。

首批运行场景：本机单用户；一条 PDF 解析／重建路线；已有模型服务；独立文本英译中及中译英。先用配置文件或 CLI 操作，界面形式在 M1 决定。

本轮范围边界：扫描件、整书、原生 LaTeX、自动路由、多设备和协作仍按原优先级推进。历史论文的扫描版可作困难样本，但不能因此把高质量 OCR 变成所有首批测试的前置条件。

## 3. 材料准备与冻结步骤

1. **登记原件**：记录英文和中文的版本、取得途径、文件名、页码／小节位置和格式。已有导入清单与哈希直接复用，不在读取、解析、对齐或交接时重算；新材料也不将哈希作为必填前置条件。尚未取得的信息留空，按当前任务需要补齐。
2. **确定输入范围**：保留正文、标题、图注和必要上下文；导读、译注、参考文献分别标记。版面测试保留原始 PDF；人工整理的纯文本只服务翻译测试。
3. **校正和对齐**：按小节、公式号和语义单位建立 1:1、1:N 或 N:1 关系；中英页码分别存储。译注、删节和无法配对部分单独标记，不强制对齐。
4. **准备质量集**：目标 24 个短段对，其中 12 个开发、12 个留出；R01／R02 尽量各占一半。实际段落不足时如实缩小规模，禁止为凑数拆坏句义。目标是可逐段人工检查，不是统计显著性评估。
5. **划分后再建库**：按连续段落或小节划分，避免相邻句被随机分到两组。开发部分用于选择提示词与确认术语；留出中文只用于评审，不进入提示词、检索库、翻译记忆或自动建库输入。记录允许提供的英文上下文。
6. **固定一版**：以 `m0-corpus-001` 记录样本、划分、术语修订和人工评审者。此后更换文本、纠正 OCR 或修改参考译文时递增版本并注明原因。

留出集一旦被用于反复调整提示词，就不再视为未使用留出集；下轮更换样本并保留历史结果。经典公开文本可能已被模型预训练见过，因此这些材料用于工程验收和相对比较，不据此宣称未知文本的泛化水平。

中译英另取 4～6 段用户原创科研说明或项目原创控制文本，重点检查限定条件、量纲和学术表达。把出版中译文回译后与英文原作比较，只能算回译实验，不能代表原创中文科研稿的翻译表现。

## 4. 术语与符号准备

先人工确认 12～20 个高频术语。每项记录来源位置、首选译名、允许变体、所属项目、适用语境和确认状态。可从以下候选开始：magnetization、magnetic moment、magnetization current、ferromagnetism、spontaneous magnetization、saturation magnetization、hysteresis loop、Curie temperature、electron scattering、single crystal、incident beam、scattering intensity。

这些是待校核词表，不是已从选定语料抽取并确认的术语库。`magnetization` 尤其要区分物理量与过程；不能全局强制替换。R02 的 H、B、M 及单位关系必须遵守原书定义，不能擅自按现代常用约定改写公式。原书确有专门讨论 H 与磁单位的内容。[Caltech 第 36 章](https://www.feynmanlectures.caltech.edu/II_36.html)

准备一项明确的共享库／项目库冲突案例，验证项目约定的优先规则；另准备同一英语词在不同上下文中的案例，防止把词库使用退化成字符串替换。人工译文修订须单独保存，不能被词库更新静默覆盖。

## 6. 验收标准与评审方式

以下为首轮操作性门槛，后续根据样本表现修订，不代表已达到质量指标。

| 维度 | 初始门槛 | 如何判定 |
|---|---|---|
| 输入完整性 | 冻结范围内每个预期正文／图注块均有处理状态；无静默漏段或重复 | 人工确认输入块清单；排除项有原因 |
| 科学含义 | 评审样本中无未解决的严重错误 | 严重错误包括结论反向、否定丢失、物理量混淆、关键数值／单位变化或虚构结果 |
| 术语 | 所有人工指定的关键概念在适用语境正确；例外可解释 | 按出现位置计数，报告正确数／适用总数，不只比较字面译法 |
| 普通表达 | 中等问题先修复再交付；轻微风格问题可记录接受 | 不因不同于出版译本的措辞直接判错 |
| 同源复用 | 无变更重跑与重导出时正文翻译请求增量为 0 | 真实请求／适配器日志与译文修订 ID；审校、解析调用分别统计 |
| PDF 结构 | 选定测试页无未解决的漏段、遮挡、错误阅读顺序及图文对应错误 | 逐页查看输出，结合输入块／公式／图注清单；不要求像素级复刻 |
| 任务控制 | 用户取消后不再派发新正文请求；在途请求与保存策略明确 | 记录取消确认时间、派发和完成事件；不假设远端请求一定可撤回 |
| 成本与耗时 | 首轮只采集基线，尚不设速度承诺 | 墙钟时间、请求数、模型返回用量；未知值写未知；估算价格注明来源和日期 |

评审先看英文／中文源文和候选译文，判断含义，再查看参考译本。正式出版译文是参考，遇到疑义回查原文；历史科学观点也不由系统自行“纠正”。区别解析错误、分段错误、翻译错误和排版错误，分别记录根因。

首轮建议由用户进行专业内容复核，代理协助定位和整理；尚未把任何自动评审视作人工确认。使用[评审记录模板](../../evaluation/review-template.md)逐条保存证据，不将单一模型自评分或字符串相似度作为通过依据。
