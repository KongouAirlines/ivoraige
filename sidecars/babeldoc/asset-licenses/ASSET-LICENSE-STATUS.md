# BabelDOC cached asset notices

This directory contains upstream license texts and copyright notices for the asset cache used by the Windows BabelDOC 0.6.4 component. It was prepared on 2026-10-11 from the 34 cached TTF files, 146 cached CMap JSON files, one ONNX model, and one tiktoken cache file. `FONT-EMBEDDED-NOTICES.txt` transcribes each cached font's OpenType copyright and license name records; it is useful where a repository license header differs from the exact binary. The other license files are copies of the linked upstream texts, except `MaruBuri-Naver-OFL.txt`, which is the paragraph text extracted from Naver's official license page, preserving its English and Korean terms.

| `cmap/*.json` (146 files) | `Adobe-CMap-LICENSE.md` | The JSON files are downloaded from [BabelDOC-Assets](https://huggingface.co/datasets/awwaawwa/BabelDOC-Assets/tree/main/cmap). Direct comparison of one file in each cached registry group—`78-EUC-H`, `B5-H`, `GB-EUC-H`, `KSC-EUC-H`, `UniAKR-UTF16-H`, `Identity-H`—with the same named [Adobe CMap source](https://github.com/adobe-type-tools/cmap-resources) found identical ordered CID ranges, except that the first five JSON files omit one 0–31 control-code range present in Adobe's current files. `Identity-H` matches exactly. The large `UniAKR-UTF16-H` character table matches 8,226 of 8,227 current Adobe entries in order, with one entry (`d881df29` → 22461) absent from the JSON. Adobe's current Chinese directory is `Adobe-GB1-6` although the cached JSON identifies the `Adobe-GB1-5` supplement. BabelDOC 0.6.4's `babeldoc/format/pdf/babelpdf/cmap.py` parses `begincidrange`/`begincidchar` syntax and loads these JSON records. The [Adobe CMap license](https://github.com/adobe-type-tools/cmap-resources/blob/master/LICENSE.md) is bundled. No pdfminer conversion code was found in this asset path, so a separate pdfminer notice is not attributed to these JSON files. |

The BabelDOC-Assets repository does not document the command used to convert Adobe's source format to JSON, so the exact conversion script and reason for the small omissions above are unknown. The direct record comparisons establish Adobe data lineage across all cached registry groups; this status does not assume a separate dataset license is needed for a format conversion. All source links above were checked on 2026-10-11. Do not replace any upstream text with a generic license template or describe Go Noto font binaries as Unlicense.
