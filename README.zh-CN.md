# ivoraige

**供人和 AI 共用、可自由组合的翻译与文件处理基础设施。**

把需要的工具放进同一个工作空间，完成翻译、审校和后续文件处理。

ivoraige 将分散的翻译和文档工具组合成可以按需选择的工作流。面向学习者、学生、科研用户，以及为爱发电的翻译者，涵盖学习笔记、论文、小说和日常阅读等场景。

我们希望为人和 AI 提供共同的基础：选用需要的能力，审阅处理结果，让已有工作在不同工具和输出格式之间延续。

*0.1.0 工作台。图中为原创样本与人工录入的译文；当前界面主要使用中文。*

## 组合适合自己的流程

- **按需增加能力。** 从文本和 Markdown 开始，需要处理 PDF 时再安装可选组件。
- **保留人工判断。** 对照原文与译文、保存草稿、接受修订，随时继续已有工作。
- **复用已接受译文。** 从同一冻结快照导出支持的格式，导出不会再次调用模型翻译。
- **选择使用方式。** 使用浏览器工作台、CLI，或通过 [MCP](docs/plan/0.1.0/mcp-guide.md) 将 AI 客户端连接到共享内核。

## 开始使用

**从源码运行 0.1.0。** 按[安装指南](docs/plan/0.1.0/installation-guide.md)准备并启动。此前的 Release 及附件已撤下，预构建下载包延后提供。源码仓库现已公开。

需要 Node.js `>=24.22.1 <25 || >=26.12.1 <27` 和 npm。源码运行可使用这两个受支持主版本内更新的稳定补丁版；Node 25 和未来主版本暂不在支持范围内。Windows 便携包构建固定使用 Node.js 26.12.1。

1. 打开工作台，导入 TXT 或 Markdown 文件。
2. 需要机器翻译时配置模型，也可以直接录入自己的译文。
3. 审校并接受修订，导出结果。

处理 PDF 时，先按 [PDF 开发参考](docs/plan/0.1.0/pdf-development.md)准备 Windows 可选环境，再按 [PDF 指南](docs/plan/0.1.0/pdf-guide.md)操作。默认在线组件源目前没有可下载的 Release。

配置、调试与贡献代码请看[开发指南](docs/plan/0.1.0/development-guide.md)。详细指南目前以中文为主。

组件安装与文档任务共享有限后台任务配额。安装期间受理的文档任务排队等待；文档任务执行时提交安装会提示冲突，可在任务结束后重试。

## 当前能力

**首个正式源码版本：`0.1.0`。** 功能和界面仍在持续完善。

| 领域 | 已有范围 |
| --- | --- |
| 文本与 Markdown | 导入、翻译任务、人工审校、Markdown/JSON 导出；Markdown 支持范围有单独说明。 |
| PDF · 可选 | 原生文本英文 PDF 到中文单语 PDF，包含来源页码定位与 PDF/Markdown/JSON 冻结导出。 |
| 保存工作 | 持久保存文档、修订、任务和导出快照。 |
| 使用入口 | 本地浏览器工作台、CLI、HTTP/SSE，以及 stdio 或 Streamable HTTP MCP。 |
| 平台 | Node.js 内核曾在 Windows、Linux、macOS 测试。PDF 开发准备已在 Windows x64 验证；目前不提供预构建下载包。 |

上述能力对应 `0.1.0` 源码，也可自行构建本地 npm 包。组件管理支持公开源匿名访问和私有源显式授权，但原默认 Release 已撤下。

扫描件 OCR、双语 PDF、EPUB、可复用术语库、Zotero 集成和通用文件处理工具仍属未来工作。在线模型会接收待译文本，并可能向你的供应商账户计费；本地工作台并不意味着翻译完全离线或免费。详细范围见[能力与限制](docs/plan/0.1.0/capabilities.md)。

## 未来方向

- 更多文档格式和基础文件处理工具，作为可选能力按需取用。
- 持久术语与更丰富的审校流程，适应不同翻译场景。
- Zotero 等工具集成，同时兼顾小说、学习和日常阅读流程。
- Index-Translate 官方 API 的专门支持。
- 以插件形式安装到 DSH，作为较低优先级的探索方向。

这些方向不代表交付日期。[0.1.x 计划](docs/plan/0.1.x/README.md)提出增量契约与工作包，不代表功能已经交付；[0.1.0 路线图](docs/plan/0.1.0/roadmap.md)保留此前方向与讨论背景。
