# ivoraige

可按需组装的通用翻译中间层，以科研英汉为首个应用。M0 材料准备与 M1 最小技术实验已完成，下一步实现 M2 文本闭环；尚无可用产品。

核心目标：不同输出共用同一份已接受译文，术语知识能够跨任务复用。
